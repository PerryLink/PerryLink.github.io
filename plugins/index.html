Plugins

43 general-purpose plugins for DeepSeek Harness, grouped into 10 categories.

These are the non-checker half of the family. They add capabilities to DeepSeek Harness itself — tools, model routing, session handling, integrations, memory, observability. Every one is published to npm, and every one is Apache-2.0 or MIT.

The other half of the family is a set of 53 compliance checkers. Those are Chinese-canonical and live under a separate index: 核查插件总览 (Chinese). They are grouped by profession rather than by capability, and each one checks a specific kind of document against the regulations or standards it cites.

Two entries in the catalog are listed twice — see the naming-caution note on the GitHub and TickTick pages. Both bare npm names belong to unrelated third-party packages on the registry, so only the scoped names are installable. This page therefore lists 43 plugins, not 45.
