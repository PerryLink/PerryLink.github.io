What it is

Phocinae is a DeepSeek Harness plugin in the integrations group, published to npm as `dsh-phocinae`. Local non-generative decision layer for DeepSeek Harness: phocinae_ask / phocinae_gate tools plus a fail-closed approval gate

Version 0.2.2, licensed Apache-2.0, Node ^22.19.0 || >=24.0.0, DSH >=0.1.6-0 <0.2.0 || >=0.2.0-0 <0.3.0.

The repository is available as a local checkout, so the version and licence above are read from the package manifest that is actually published rather than from a registry copy.

Other plugins in the same group: Certification MCP, Claude Move, GitHub, MCP Panel, Reach, TickTick.

Install

The plugin is installed with dsh plugin add. Same command on both platforms — only the verification line differs.

bash / sh

dsh plugin --profile default add dsh-phocinae
dsh --profile default --dump-config | grep 'dsh-phocinae'

PowerShell

dsh plugin --profile default add dsh-phocinae
dsh --profile default --dump-config | Select-String 'dsh-phocinae'

Replace default with the profile you actually use. Restart the session afterwards so the plugin’s tools are registered.
