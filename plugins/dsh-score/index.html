What it is

Score is a DeepSeek Harness plugin in the development & quality group, published to npm as `dsh-score`. Plugin quality scoring for the DSH ecosystem: evaluate plugins against checks and produce evidence-backed compliance reports.

Version 0.2.19, licensed Apache-2.0, Node ^22.19.0 || >=24.0.0, DSH >=0.1.2-rc.1 <0.2.0 || >=0.1.5-alpha.1 <0.2.0 || >=0.1.6-0 <0.2.0 || >=0.1.7-0 <0.2.0 || >=0.2.0-0 <0.3.0 || >=0.2.1-0 <0.3.0.

The repository is available as a local checkout, so the version and licence above are read from the package manifest that is actually published rather than from a registry copy.

Other plugins in the same group: Defend, Observe, Plugin Doctor, Plugin Kit, Plugin Upgrade, Test Drive.

Install

Install through the dsh plugin command; the two shells differ only in how the second line confirms the result.

bash / sh

dsh plugin --profile default add dsh-score
dsh --profile default --dump-config | grep 'dsh-score'

PowerShell

dsh plugin --profile default add dsh-score
dsh --profile default --dump-config | Select-String 'dsh-score'

Substitute your own profile name for default, then restart the session — installation alone does not hot-load the plugin.
