PerryLink DSH Plugin Family

53 compliance checkers and 43 general-purpose plugins for DeepSeek Harness. This page is the orientation; the two indexes below are where the actual listings are.

What this family is

Two plugin families that share an author and a contract, published to npm and developed in the open on GitHub.

The compliance checkers (53 plugins) take a document — a hazardous-chemical register, a medical record front sheet, a bid response, a FMEA worksheet, a letter of credit — and compare it, item by item, against the regulations, national standards and ministry documents the plugin declares as its basis. Each plugin ships a versioned rule pack as data, not code, so the rule set can be replaced without touching the plugin. The output is a list of differences with positions and the clause each difference was checked against. The family's standing rule is that the plugins list differences; they do not adjudicate — no compliance verdicts, no liability findings, no substitutes for a reviewer.

Those 53 plugins are Chinese-canonical and documented in Chinese, because the documents they check against are Chinese. They are indexed under 核查插件总览, grouped by profession, with a decision table at 该用哪个核查插件 that maps “what document do I have?” to “which plugin do I run?”.

The general-purpose plugins (43 plugins) extend DeepSeek Harness itself: tools, model routing, session management, memory, observability, integrations and development quality gates. They are grouped by category at /plugins/.

The 53 compliance checkers, by profession

  • 招投标 — 面向招标人、招标代理与投标人的文件级核对：投标文件符合性、投标人资格、评标因素评分矩阵、质疑与投诉期限。
  • 工程建设 — 面向施工、监理与建设单位的现场与报批文件核对：安全技术交底、监理日志、危大工程、环评导则、土壤与地下水监测。
  • 安全生产 — 面向生产经营单位安全管理岗的台账与预案核对：危化品临界量、应急预案要素、演练脚本、隐患判定、两票与线损。
  • 医疗病案 — 面向病案室、质控科与临床科室的病历与编码核对：病案首页、护理记录、ICD 编码结构与星剑号配对。
  • 公文档案 — 面向办公室、文秘与档案室的公文与归档核对：公文格式要素、文种与发文字号、流转时限、归档完整性与保管期限。
  • 关务外贸 — 面向报关、单证与供应链合规岗的关务核对：报关单证一致、商品归类层级、原产地 RVC、出口管制、信用证与滞箱费台账。
  • 质量制造 — 面向质量管理与工艺岗的体系文件核对：FMEA 分析表、PPAP 提交要素、SPC 控制图常数与过程能力、审核意见闭环。
  • 科研教育 — 面向科研管理、基金管理与教研岗的申报与评审材料核对：基金申请书形式审查、试卷解析结构、作文量表评分、政策专报。
  • 法律诉讼 — 面向律师与法务的诉讼文书核对：起诉状四要素、证据清单齐备性、法条引用与文书要素的可核验性。
  • 国企治理 — 面向国有企业治理与内控岗的程序留痕核对：三重一大决策台账、作业规程与 FMEA／控制计划的一致性。

The citation count is the point of this family, so it is stated plainly: of 408 rules, 163 rest on a clause whose verbatim text could not be obtained. Those rules are labelled derived from principle, their severity is capped at warn, and the rule pack says so in the field where the quotation would go. Nothing is paraphrased and then presented as a quotation.

About this site

This is plain static HTML. Every page is complete in the served response — there is no client-side rendering, no SPA shell, and no JavaScript at all. The build is a single zero-dependency Node ESM script that reads a pinned snapshot of the catalog and each plugin's own rule pack, and writes the HTML. Search engines and language models see exactly the text a browser sees.

This site is plain static HTML: all text is present in the served HTML with no JavaScript rendering. Content is generated by the build script from each plugin’s own rule pack and package metadata.
