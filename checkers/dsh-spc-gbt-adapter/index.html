这个插件核对什么

控制图常数核对（dsh-spc-gbt-adapter）是一个面向质量制造场景的 DeepSeek Harness 核查插件。控制图常数与过程能力指数核对（按 GB/T 4091 的常规控制图常数表核对控制限与 Cp/Cpk 的自洽性，仅提示差异，不作出定性结论）

规则库共 7 条规则，覆盖面与人工复核一遍的注意力分配大致相当。该规则库的规则依据构成为：由原则推导 6 条、本机构配置 1 条。

核对方式

控制图常数核对的检查手段集中在以下几类，都不依赖模型判断：。

检查过程不引入任何外部信息：没有数据库查询、没有网络请求、没有模型参与，同样输入必然得到同样输出。

该规则库不涉及数值计算：它看的是要素齐不齐、取值在不在允许范围内、字段之间对不对得上。

它不作什么判断

把它当成一次机械的交叉核对，而不是一次评审。核对结果里不会出现「合规」「不合格」这类字样，只有「此处与所引依据不一致」以及不一致的具体位置。

结果里最高的严重度是「提示」。这不是保守，而是如实的：这些规则所对照的条文没有逐字文本，凭原则推导不足以支撑更强的结论。

其中 1 条规则的阈值或清单来自使用机构自身配置，而不是国家标准。这类规则在更换机构后必须先改配置再使用，否则会拿别的机构的口径核对本机构的材料。

规则库中未被命中的规则同样会出现在结果里：无法执行的检查会连同原因一起列出，空的结果列表不等于材料没有问题，只等于规则库覆盖到的那部分没有发现差异。

结果怎么读

本插件共 7 条规则，其中严重度最高的一档是「提示」，共 6 条：SP-001、SP-002、SP-003、SP-004、SP-006、SP-007。这些规则命中时应当优先处理，其余规则的结果可以在其后逐条确认。

另有 7 条规则的条文本次未取得逐字文本（SP-001、SP-002、SP-003、SP-004、SP-005、SP-006、SP-007）。引用这部分结果时请注意措辞：它们是原则推导的产物，不是条文比对的结果。

还有 1 条规则属于「本机构配置」（SP-005）。它们的判据来自配置项而不是国家标准，配置未填时这几条会进入跳过项。

适用场景与同组插件

面向质量管理与工艺岗的体系文件核对：FMEA 分析表、PPAP 提交要素、SPC 控制图常数与过程能力、审核意见闭环。

同一职业分组「质量制造」下还有 7 个核查插件，分别是FMEA 表核对（dsh-fmea-table-check）、点评回复核对（dsh-ota-review-check）、项目链条核对（dsh-pipeline-check）、PPAP 要素核对（dsh-ppap-check）、维修工单核对（dsh-repair-order-qc）、审稿回应核对（dsh-review-reply-check） 等。这类材料通常需要同时过几个插件：一个插件只覆盖它自己那份规则库声明过的范围，把几个插件的结果合起来看才是完整的一次复核。

npm 包名 dsh-spc-gbt-adapter，仓库 PerryLink/dsh-spc-gbt-adapter，Apache-2.0 许可。页面上的规则与依据由构建脚本从规则库（版本 2026.1）与包的 locale 资源读出，与仓库内容一致。

  • FMEA 表核对 dsh-fmea-table-check —— FMEA 分析表要素齐备性与风险顺序数一致性核对
  • 点评回复核对 dsh-ota-review-check —— 在线点评回复台账核对
  • 项目链条核对 dsh-pipeline-check —— 项目全流程文件链条核对
  • PPAP 要素核对 dsh-ppap-check —— PPAP 提交要素齐备性核对
  • 维修工单核对 dsh-repair-order-qc —— 维修工单结算核对
  • 审稿回应核对 dsh-review-reply-check —— 审稿意见逐条回应覆盖核对
  • 质保索赔核对 dsh-warranty-calc —— 质保期与索赔金额核对

安装

插件通过 dsh plugin add 安装，两条命令的主体一致，区别只在装完后用什么方式确认它已经注册：

bash / sh

dsh plugin --profile default add dsh-spc-gbt-adapter
dsh --profile default --dump-config | grep 'dsh-spc-gbt-adapter'

PowerShell

dsh plugin --profile default add dsh-spc-gbt-adapter
dsh --profile default --dump-config | Select-String 'dsh-spc-gbt-adapter'

上面的 default 是占位，换成你自己的 profile。确认配置里能搜到包名，再重开会话使用。
