这个插件核对什么

滞箱费台账核对（dsh-demurrage-ledger）是一个面向关务外贸场景的 DeepSeek Harness 核查插件。滞箱费台账核对（按免箱期与费率核对超期天数与金额的自洽性，仅提示差异，不作出定性结论）

7 条规则，是本族里最常见的一档规模，大体对应一次认真的人工通读能看住的范围。规则库中没有任何一条声称自己依据了逐字条文：全部为「由原则推导」，最高严重度因此只到「提示」。

它不作什么判断

共同约定只有一条——插件只做「指出不一致」，不做「下结论」。差异清单里每条都带规则编号、依据的文件与条款、以及差异落在材料里的位置。

本插件不产生「错误」级结果，严重度最高为「提示」。它指出的是「此处与依据不一致」，而不是「此处是错的」。

规则库中未被命中的规则同样会出现在结果里：无法执行的检查会连同原因一起列出，空的结果列表不等于材料没有问题，只等于规则库覆盖到的那部分没有发现差异。

适用场景与同组插件

面向报关、单证与供应链合规岗的关务核对：报关单证一致、商品归类层级、原产地 RVC、出口管制、信用证与滞箱费台账。

同一职业分组「关务外贸」下还有 7 个核查插件，分别是报关单证核对（dsh-customs-doc-check）、出口管制核对（dsh-export-ctl-check）、预测考核核对（dsh-forecast-penalty）、归类层级核对（dsh-hs-classify）、信用证单据核对（dsh-lc-doc-check）、原产地 RVC 核对（dsh-origin-rvc-check） 等。实际使用中往往要跑不止一个：单个插件只负责它自己那份规则库声明过的范围，范围之间不重叠，合起来才接近一次完整复核。

发布渠道是 npm 包 dsh-demurrage-ledger，源码在 GitHub 的 PerryLink/dsh-demurrage-ledger，许可为 Apache-2.0。本页的规则清单直接取自仓库里的规则库文件（版本 2026.1），不是手写的介绍。

  • 报关单证核对 dsh-customs-doc-check —— 报关单证一致性核对
  • 出口管制核对 dsh-export-ctl-check —— 出口管制物项核对
  • 预测考核核对 dsh-forecast-penalty —— 预测准确率考核核对
  • 归类层级核对 dsh-hs-classify —— 商品归类层级一致性核对
  • 信用证单据核对 dsh-lc-doc-check —— 信用证单据条款核对
  • 原产地 RVC 核对 dsh-origin-rvc-check —— 原产地区域价值成分核对
  • 施工天窗核对 dsh-railway-window —— 铁路施工天窗台账核对

安装

安装分两步——先 add，再确认它进了配置。两条命令都与平台无关，只有过滤输出的写法不同：

bash / sh

dsh plugin --profile default add dsh-demurrage-ledger
dsh --profile default --dump-config | grep 'dsh-demurrage-ledger'

PowerShell

dsh plugin --profile default add dsh-demurrage-ledger
dsh --profile default --dump-config | Select-String 'dsh-demurrage-ledger'

上面的 default 是占位，换成你自己的 profile。确认配置里能搜到包名，再重开会话使用。
