这个插件核对什么

线损拆分核对（dsh-power-loss-split）是一个面向安全生产场景的 DeepSeek Harness 核查插件。线损电量拆分与考核表核对（依据公开的线损计算口径，仅提示差异，不作出定性结论）

5 条规则构成了它的全部核对范围，规则数量在本族中偏少，换来的是每条规则都足够具体。规则库的依据类型分布是 由原则推导 3 条、本机构配置 2 条。

核对方式

从检查方式看，线损拆分核对用的是几类可以机械判定的手段：。

所有检查都只在材料内部完成——不连外部数据库、不联网、不请模型裁决，所以同一份材料在相同配置下重复跑，结果逐字相同。

该规则库不涉及数值计算：它看的是要素齐不齐、取值在不在允许范围内、字段之间对不对得上。

它不作什么判断

这个插件不提供结论，只提供线索：材料内部可以逐条指认的不一致会被列出来，每条都标明它对照的规则、依据的文件与条款、以及差异在材料中的位置。是否构成问题、是否需要整改，由看到这份清单的人判断。

严重度上限为「提示」——插件不使用「错误」级，因此结果里不会出现任何定性判断。

需要注意 2 条「本机构配置」类规则：它们的阈值与清单由使用机构自己填入，插件不自带。配置为空时这些规则不会执行，而是把自己列进跳过项。

结果里的空清单有明确含义，插件对此不作暗示：规则库覆盖不到的部分、以及因缺少必要字段而无法执行的检查，都会单独列出原因。

规则清单

规则库 power-loss-split.yaml 的全部 5 条规则（规则库版本 2026.1）
规则检查内容严重度依据类型
PL-001线损电量应等于供电量减售电量提示由原则推导
PL-002线损率应等于线损电量与供电量之比提示由原则推导
PL-003线损率应在本机构配置的考核区间内参考本机构配置
PL-004计量点电量合计应与售电量（或供电量）一致提示由原则推导
PL-005三相不平衡度应不超过本机构配置的限值参考本机构配置

严重度含义：提示（3 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（2 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：由原则推导（3 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」；本机构配置（2 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」。

引用取证状态

引用取证：没有可直接对照的条文。5 条规则的依据类型为「由原则推导」或「本机构配置」，规则库不引用任何条文原文，也就没有取证欠账一说。这类规则的结论强度低于条文比对，使用时应按线索而非结论对待。

把规则按所引文件归并，得到 1 份依据文件，各自被引用的规则数是：《电力网电能损耗计算导则》（5 条）。同一文件的不同条款会被多条规则分别引用，因此上面是文件层面的汇总。

结果怎么读

本插件共 5 条规则，其中严重度最高的一档是「提示」，共 3 条：PL-001、PL-002、PL-004。结果里先看这几条，再回头处理其他规则报出的差异。

还有 2 条规则属于「本机构配置」（PL-003、PL-005）。这几条只有在配置被填写后才会执行；未配置时它们不会静默通过，而是列入跳过。

适用场景与同组插件

面向生产经营单位安全管理岗的台账与预案核对：危化品临界量、应急预案要素、演练脚本、隐患判定、两票与线损。

同一职业分组「安全生产」下还有 6 个核查插件，分别是养殖投入品核对（dsh-aqua-input-check）、演练脚本核对（dsh-drill-script-check）、应急预案要素校验（dsh-emergency-plan）、危化品临界量核对（dsh-hazchem-check）、重大隐患条款映射（dsh-hidden-risk-map）、电力工作票核对（dsh-power-ticket-check）。这类材料通常需要同时过几个插件：一个插件只覆盖它自己那份规则库声明过的范围，把几个插件的结果合起来看才是完整的一次复核。

  • 养殖投入品核对 dsh-aqua-input-check —— 水产养殖投入品记录核对
  • 演练脚本核对 dsh-drill-script-check —— 应急演练脚本核对
  • 应急预案要素校验 dsh-emergency-plan —— 应急预案要素齐备性与条款级页码定位

  • 重大隐患条款映射 dsh-hidden-risk-map —— 安全隐患台账→《工贸企业重大事故隐患判定标准》
  • 电力工作票核对 dsh-power-ticket-check —— 电力工作票要素齐备性与签发许可顺序核对

安装

下面是安装命令。两个平台用的都是 dsh，第二行是确认安装结果的写法，按你所在的 shell 选一条：

bash / sh

dsh plugin --profile default add dsh-power-loss-split
dsh --profile default --dump-config | grep 'dsh-power-loss-split'

PowerShell

dsh plugin --profile default add dsh-power-loss-split
dsh --profile default --dump-config | Select-String 'dsh-power-loss-split'

上面的 default 是占位，换成你自己的 profile。确认配置里能搜到包名，再重开会话使用。
