这个插件核对什么

应急预案要素校验（dsh-emergency-plan）是一个面向安全生产场景的 DeepSeek Harness 核查插件。应急预案要素齐备性与条款级页码定位（依据 GB/T 29639-2020 等公开文件，仅提示差异，不作出定性结论）

规则库共 9 条规则，覆盖面与人工复核一遍的注意力分配大致相当。该规则库同时包含「条文直接规定」与「由原则推导」两类依据：前者 5 条，后者 3 条，另有 1 条取自使用机构自身配置。

核对方式

从检查方式看，应急预案要素校验用的是几类可以机械判定的手段：。

检查过程不引入任何外部信息：没有数据库查询、没有网络请求、没有模型参与，同样输入必然得到同样输出。

这里没有算术核对——规则库处理的是齐备性、取值合法性与字段关系，不重算任何金额或数量。

它不作什么判断

本族插件的共同约定是：只列出材料内部可以逐条指认的差异，不判定合规、不认定责任、不替代主管部门或审核人的结论。报告里每一条差异都会带上它对照的规则、依据的文件与条款，以及差异的具体位置。

本插件不产生「错误」级结果，严重度最高为「提示」。它指出的是「此处与依据不一致」，而不是「此处是错的」。

另有 1 条规则的判据来自使用机构自己的配置项，不是国家标准。换机构使用前必须先替换这份配置，否则核对的是别人的口径。

规则库中未被命中的规则同样会出现在结果里：无法执行的检查会连同原因一起列出，空的结果列表不等于材料没有问题，只等于规则库覆盖到的那部分没有发现差异。

严重度含义：提示（5 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（4 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：条文直接规定（5 条）——该规则的依据条文已取得逐字文本，规则直接对照条文规定；由原则推导（3 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」；本机构配置（1 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」。

引用取证状态

引用取证：可以逐字对照条文的规则共 5 条，没有一条规则标注「本次未取得」。这意味着规则库对自身依据的声明是完整的：要么引用条文原文，要么明确说明依据并非条文。

规则库落在 2 份文件上，分布如下：《生产经营单位生产安全事故应急预案编制导则》（8 条）、《生产安全事故应急预案管理办法》（1 条）。同一份文件在不同规则中可能被引用于不同条款。

结果怎么读

本插件共 9 条规则，其中严重度最高的一档是「提示」，共 5 条：EP-001、EP-002、EP-003、EP-004、EP-007。这几条是清单里最需要先看的；其余条目按材料实际内容逐条判断即可。

还有 1 条规则属于「本机构配置」（EP-008）。使用前请确认这几条的配置与本机构口径一致，否则核对的是别人的标准。

适用场景与同组插件

面向生产经营单位安全管理岗的台账与预案核对：危化品临界量、应急预案要素、演练脚本、隐患判定、两票与线损。

同一职业分组「安全生产」下还有 6 个核查插件，分别是养殖投入品核对（dsh-aqua-input-check）、演练脚本核对（dsh-drill-script-check）、危化品临界量核对（dsh-hazchem-check）、重大隐患条款映射（dsh-hidden-risk-map）、线损拆分核对（dsh-power-loss-split）、电力工作票核对（dsh-power-ticket-check）。这几个插件的范围彼此不重叠，也不会互相替代；要覆盖这类材料的全貌，需要挑出对应的几个分别跑。

发布渠道是 npm 包 dsh-emergency-plan，源码在 GitHub 的 PerryLink/dsh-emergency-plan，许可为 Apache-2.0。本页的规则清单直接取自仓库里的规则库文件（版本 2026.1），不是手写的介绍。

  • 养殖投入品核对 dsh-aqua-input-check —— 水产养殖投入品记录核对
  • 演练脚本核对 dsh-drill-script-check —— 应急演练脚本核对
  • 危化品临界量核对 dsh-hazchem-check —— 危险化学品临界量与重大危险源辨识核对
  • 重大隐患条款映射 dsh-hidden-risk-map —— 安全隐患台账→《工贸企业重大事故隐患判定标准》
  • 线损拆分核对 dsh-power-loss-split —— 线损电量拆分与考核表核对
  • 电力工作票核对 dsh-power-ticket-check —— 电力工作票要素齐备性与签发许可顺序核对

安装

安装命令对两个平台是同一个 dsh 子命令，只有随后确认安装结果的那一步按 shell 不同：

bash / sh

dsh plugin --profile default add dsh-emergency-plan
dsh --profile default --dump-config | grep 'dsh-emergency-plan'

PowerShell

dsh plugin --profile default add dsh-emergency-plan
dsh --profile default --dump-config | Select-String 'dsh-emergency-plan'

profile 名按实际情况替换。注意安装本身不会热加载——重开会话之后插件才生效。
