这个插件核对什么

法条引用核对（dsh-lawcite-adapter）是一个面向法律诉讼场景的 DeepSeek Harness 核查插件。法条引用与文书要素核对（按名称、条号、原文与效力状态核对引用可核验性，仅提示差异，不作出定性结论）

规则库 8 条规则，数量居中：既能覆盖这类材料的主要要素，又不会把无关项也拉进来。按依据类型拆开看：本机构配置 8 条。

核对方式

法条引用核对的检查手段集中在以下几类，都不依赖模型判断：多字段至少填一（2 条）、格式须匹配规定形式（1 条）、必填项存在性（1 条）、取值须在允许清单内（1 条）、表头要素存在性（1 条）、编号或键不得重复（1 条）。此外还有 1 类出现频次较低的检查方式。

检查过程不引入任何外部信息：没有数据库查询、没有网络请求、没有模型参与，同样输入必然得到同样输出。

需要说明的是，该规则库不做任何数值运算，核对的是要素是否齐备、取值是否在允许范围内、字段之间的关系是否自洽。

它不作什么判断

本族插件的共同约定是：只列出材料内部可以逐条指认的差异，不判定合规、不认定责任、不替代主管部门或审核人的结论。报告里每一条差异都会带上它对照的规则、依据的文件与条款，以及差异的具体位置。

本插件不产生「错误」级结果，严重度最高为「提示」。它指出的是「此处与依据不一致」，而不是「此处是错的」。

需要注意 8 条「本机构配置」类规则：它们的阈值与清单由使用机构自己填入，插件不自带。配置为空时这些规则不会执行，而是把自己列进跳过项。

规则库中未被命中的规则同样会出现在结果里：无法执行的检查会连同原因一起列出，空的结果列表不等于材料没有问题，只等于规则库覆盖到的那部分没有发现差异。

上表来自插件声明的 normativeBasis；规则库内部还会把每条规则落到具体条款上。条款原文的取证情况见下一节。

引用取证状态

引用取证：8 条规则全部为「由原则推导」，没有一条声称依据了逐字条文。其中 7 条如实标注「本次未取得」。这意味着结果里的每一条差异都只能作为线索，不能作为「违反某条条文」的结论。

规则库落在 3 份文件上，分布如下：本机构法律文书审查口径（本机构配置）—— 原挂《党政机关公文格式》GB/T 9704—2012，已核实为版式标准（6 条）、本机构法律文书审查口径（本机构配置）—— 原挂《中华人民共和国立法法》，已核实其第六十五条为立法技术条款（1 条）、本机构法律文书审查办法（本机构配置）（1 条）。引用数统计到文件一层；同一文件内的不同条款可能分别支撑不同规则。

结果怎么读

本插件共 8 条规则，其中严重度最高的一档是「参考」，共 8 条：LC-001、LC-002、LC-003、LC-004、LC-005、LC-006、LC-007、LC-008。结果里先看这几条，再回头处理其他规则报出的差异。

另有 7 条规则的条文本次未取得逐字文本（LC-002、LC-003、LC-004、LC-005、LC-006、LC-007、LC-008）。这些规则报出的差异只能作为线索，不能当作「违反某条条文」来引用。

还有 8 条规则属于「本机构配置」（LC-001、LC-002、LC-003、LC-004、LC-005、LC-006、LC-007、LC-008）。它们的判据来自配置项而不是国家标准，配置未填时这几条会进入跳过项。

适用场景与同组插件

面向律师与法务的诉讼文书核对：起诉状四要素、证据清单齐备性、法条引用与文书要素的可核验性。

同一职业分组「法律诉讼」下还有 2 个核查插件，分别是证据清单核对（dsh-evidence-check）、诉状要素核对（dsh-pleading-draft）。实际使用中往往要跑不止一个：单个插件只负责它自己那份规则库声明过的范围，范围之间不重叠，合起来才接近一次完整复核。

该插件以 npm 包 dsh-lawcite-adapter 发布，仓库在 GitHub 的 PerryLink/dsh-lawcite-adapter，采用 Apache-2.0 许可。本页内容由构建脚本从插件自身的规则库与 locale 资源生成，与仓库中的规则库版本 2026.1 对应。

  • 证据清单核对 dsh-evidence-check —— 证据清单齐备性核对
  • 诉状要素核对 dsh-pleading-draft —— 起诉状要素齐备性核对

安装

下面是安装命令。两个平台用的都是 dsh，第二行是确认安装结果的写法，按你所在的 shell 选一条：

bash / sh

dsh plugin --profile default add dsh-lawcite-adapter
dsh --profile default --dump-config | grep 'dsh-lawcite-adapter'

PowerShell

dsh plugin --profile default add dsh-lawcite-adapter
dsh --profile default --dump-config | Select-String 'dsh-lawcite-adapter'

profile 名按实际情况替换。注意安装本身不会热加载——重开会话之后插件才生效。
