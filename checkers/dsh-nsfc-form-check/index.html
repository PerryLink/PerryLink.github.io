这个插件核对什么

基金申请书形式审查（dsh-nsfc-form-check）是一个面向科研教育场景的 DeepSeek Harness 核查插件。国家自然科学基金申请书形式审查与匿名化提示（依据《国家自然科学基金条例》与申请人导入的当年指南，仅提示差异，不作出定性结论）

15 条规则构成了本族里较完整的一套核对，落到的要素比多数插件更多。规则库的依据类型分布是 由原则推导 10 条、本机构配置 5 条。

核对方式

从检查方式看，基金申请书形式审查用的是几类可以机械判定的手段：。

检查过程不引入任何外部信息：没有数据库查询、没有网络请求、没有模型参与，同样输入必然得到同样输出。

该规则库不涉及数值计算：它看的是要素齐不齐、取值在不在允许范围内、字段之间对不对得上。

它不作什么判断

把它当成一次机械的交叉核对，而不是一次评审。核对结果里不会出现「合规」「不合格」这类字样，只有「此处与所引依据不一致」以及不一致的具体位置。

结果里最高的严重度是「提示」。这不是保守，而是如实的：这些规则所对照的条文没有逐字文本，凭原则推导不足以支撑更强的结论。

另有 5 条规则的判据来自使用机构自己的配置项，不是国家标准。换机构使用前必须先替换这份配置，否则核对的是别人的口径。

结果里的空清单有明确含义，插件对此不作暗示：规则库覆盖不到的部分、以及因缺少必要字段而无法执行的检查，都会单独列出原因。

严重度含义：提示（4 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（11 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：由原则推导（10 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」；本机构配置（5 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」。

上表来自插件声明的 normativeBasis；规则库内部还会把每条规则落到具体条款上。条款原文的取证情况见下一节。

引用取证状态

引用取证：没有可直接对照的条文。15 条规则的依据类型为「由原则推导」或「本机构配置」，规则库不引用任何条文原文，也就没有取证欠账一说。这类规则的结论强度低于条文比对，使用时应按线索而非结论对待。

规则库合计引用 2 份文件，引用规则数依次为：《国家自然科学基金条例》（13 条）、《2026 年度国家自然科学基金项目指南·申请规定》（2 条）。引用数统计到文件一层；同一文件内的不同条款可能分别支撑不同规则。

结果怎么读

本插件共 15 条规则，其中严重度最高的一档是「提示」，共 4 条：NF-001、NF-002、NF-003、NF-004。这几条是清单里最需要先看的；其余条目按材料实际内容逐条判断即可。

还有 5 条规则属于「本机构配置」（NF-010、NF-011、NF-012、NF-014、NF-015）。使用前请确认这几条的配置与本机构口径一致，否则核对的是别人的标准。

适用场景与同组插件

面向科研管理、基金管理与教研岗的申报与评审材料核对：基金申请书形式审查、试卷解析结构、作文量表评分、政策专报。

同一职业分组「科研教育」下还有 4 个核查插件，分别是量表评分核对（dsh-essay-rubric-check）、能力差距核对（dsh-learning-gap-check）、试卷结构核对（dsh-paper-doc-adapter）、政策专报核对（dsh-policy-brief-draft）。实际使用中往往要跑不止一个：单个插件只负责它自己那份规则库声明过的范围，范围之间不重叠，合起来才接近一次完整复核。

发布渠道是 npm 包 dsh-nsfc-form-check，源码在 GitHub 的 PerryLink/dsh-nsfc-form-check，许可为 Apache-2.0。本页的规则清单直接取自仓库里的规则库文件（版本 2026.1），不是手写的介绍。

  • 量表评分核对 dsh-essay-rubric-check —— 作文量表评分核对
  • 能力差距核对 dsh-learning-gap-check —— 能力差距与培养计划核对

安装

先在 bash 或 PowerShell 里装上，再确认配置里出现了这个包名：

bash / sh

dsh plugin --profile default add dsh-nsfc-form-check
dsh --profile default --dump-config | grep 'dsh-nsfc-form-check'

PowerShell

dsh plugin --profile default add dsh-nsfc-form-check
dsh --profile default --dump-config | Select-String 'dsh-nsfc-form-check'

上面的 default 是占位，换成你自己的 profile。确认配置里能搜到包名，再重开会话使用。
