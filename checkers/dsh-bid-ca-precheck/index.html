这个插件核对什么

投标符合性预检（dsh-bid-ca-precheck）是一个面向招投标场景的 DeepSeek Harness 核查插件。投标文件符合性预检（按招标文件逐条核对响应情况，仅提示差异，不作出定性结论）

6 条规则构成了它的全部核对范围，规则数量在本族中偏少，换来的是每条规则都足够具体。依据来源是混合的：「条文直接规定」2 条、「由原则推导」3 条、取自使用机构自身配置 1 条。两类规则的证据强度不同，结果里的严重度已经反映了这个差别。

插件不会替你查证。它只比较材料自身各处之间、以及材料与所引条款之间是否一致；材料里写错的事实，只要内部自洽，就查不出来。

需要说明的是，该规则库不做任何数值运算，核对的是要素是否齐备、取值是否在允许范围内、字段之间的关系是否自洽。

它不作什么判断

共同约定只有一条——插件只做「指出不一致」，不做「下结论」。差异清单里每条都带规则编号、依据的文件与条款、以及差异落在材料里的位置。

本插件不产生「错误」级结果，严重度最高为「提示」。它指出的是「此处与依据不一致」，而不是「此处是错的」。

需要注意 1 条「本机构配置」类规则：它们的阈值与清单由使用机构自己填入，插件不自带。配置为空时这些规则不会执行，而是把自己列进跳过项。

结果里的空清单有明确含义，插件对此不作暗示：规则库覆盖不到的部分、以及因缺少必要字段而无法执行的检查，都会单独列出原因。

严重度含义：提示（5 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（1 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：条文直接规定（2 条）——该规则的依据条文已取得逐字文本，规则直接对照条文规定；本机构配置（1 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」；由原则推导（3 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」。

引用取证状态

取证情况需要分开看：2 条规则可以逐字对照条文，1 条不能。不能对照的那部分没有被隐藏或改写成看似引文的样子，规则库里直接写着未取得。

规则引用的文件共 2 份，按引用规则数排列为：《中华人民共和国招标投标法》（5 条）、《中华人民共和国招标投标法实施条例》（1 条）。同一文件的不同条款会被多条规则分别引用，因此上面是文件层面的汇总。

结果怎么读

本插件共 6 条规则，其中严重度最高的一档是「提示」，共 5 条：BC-001、BC-003、BC-004、BC-005、BC-006。这几条是清单里最需要先看的；其余条目按材料实际内容逐条判断即可。

另有 1 条规则的条文本次未取得逐字文本（BC-002）。这些规则报出的差异只能作为线索，不能当作「违反某条条文」来引用。

还有 1 条规则属于「本机构配置」（BC-002）。它们的判据来自配置项而不是国家标准，配置未填时这几条会进入跳过项。

适用场景与同组插件

面向招标人、招标代理与投标人的文件级核对：投标文件符合性、投标人资格、评标因素评分矩阵、质疑与投诉期限。

同一职业分组「招投标」下还有 6 个核查插件，分别是资格条件核对（dsh-bid-qual-check）、合同立场核对（dsh-contract-stance）、质疑投诉期限核对（dsh-protest-deadline）、规则库自检（dsh-rulefile-check）、招标条款摘录核对（dsh-tender-extract）、评分矩阵核对（dsh-tender-matrix）。这几个插件的范围彼此不重叠，也不会互相替代；要覆盖这类材料的全貌，需要挑出对应的几个分别跑。

该插件以 npm 包 dsh-bid-ca-precheck 发布，仓库在 GitHub 的 PerryLink/dsh-bid-ca-precheck，采用 Apache-2.0 许可。本页内容由构建脚本从插件自身的规则库与 locale 资源生成，与仓库中的规则库版本 2026.1 对应。

  • 资格条件核对 dsh-bid-qual-check —— 投标人资格条件核对
  • 合同立场核对 dsh-contract-stance —— 合同条款立场台账核对
  • 质疑投诉期限核对 dsh-protest-deadline —— 质疑与投诉期限核对
  • 规则库自检 dsh-rulefile-check —— 规则库文件自检核对
  • 招标条款摘录核对 dsh-tender-extract —— 招标文件条款摘录核对
  • 评分矩阵核对 dsh-tender-matrix —— 评标因素评分矩阵核对

安装

安装分两步——先 add，再确认它进了配置。两条命令都与平台无关，只有过滤输出的写法不同：

bash / sh

dsh plugin --profile default add dsh-bid-ca-precheck
dsh --profile default --dump-config | grep 'dsh-bid-ca-precheck'

PowerShell

dsh plugin --profile default add dsh-bid-ca-precheck
dsh --profile default --dump-config | Select-String 'dsh-bid-ca-precheck'

若你用的不是 default profile，把名字替换掉即可。安装后需要重启会话，工具才会注册进来。
