这个插件核对什么

试卷结构核对（dsh-paper-doc-adapter）是一个面向科研教育场景的 DeepSeek Harness 核查插件。试卷解析结构核对（按题型、答案、分值与 yotta 标识核对试卷结构自洽，仅提示差异，不作出定性结论）

8 条规则，是本族里最常见的一档规模，大体对应一次认真的人工通读能看住的范围。该规则库的规则依据构成为：由原则推导 6 条、本机构配置 2 条。

核对方式

从检查方式看，试卷结构核对用的是几类可以机械判定的手段：多字段至少填一（2 条）、求和结果一致（1 条）、取值须在允许清单内（1 条）、须为可解析数值（1 条）、编号或键不得重复（1 条）、必填项存在性（1 条）。此外还有 1 类出现频次较低的检查方式。

插件不会替你查证。它只比较材料自身各处之间、以及材料与所引条款之间是否一致；材料里写错的事实，只要内部自洽，就查不出来。

它不作什么判断

这一族插件的立场一致：把材料内部能够逐条指认的差异列出来，合规与否、责任归属、以及能否通过审核，都不由插件给出。每条差异都附上它对照的规则、依据的文件与条款和差异位置，便于逐个复核。

严重度上限为「提示」——插件不使用「错误」级，因此结果里不会出现任何定性判断。

其中 2 条规则的阈值或清单来自使用机构自身配置，而不是国家标准。这类规则在更换机构后必须先改配置再使用，否则会拿别的机构的口径核对本机构的材料。

结果里的空清单有明确含义，插件对此不作暗示：规则库覆盖不到的部分、以及因缺少必要字段而无法执行的检查，都会单独列出原因。

引用取证状态

引用取证：8 条规则全部为「由原则推导」，没有一条声称依据了逐字条文。其中 8 条如实标注「本次未取得」。这意味着结果里的每一条差异都只能作为线索，不能作为「违反某条条文」的结论。

规则引用的文件共 2 份，按引用规则数排列为：《试题元数据规范》（6 条）、本机构题库与命题口径（本机构配置）（2 条）。同一文件的不同条款会被多条规则分别引用，因此上面是文件层面的汇总。

结果怎么读

本插件共 8 条规则，其中严重度最高的一档是「提示」，共 6 条：PD-001、PD-002、PD-003、PD-006、PD-007、PD-008。结果里先看这几条，再回头处理其他规则报出的差异。

另有 8 条规则的条文本次未取得逐字文本（PD-001、PD-002、PD-003、PD-004、PD-005、PD-006、PD-007、PD-008）。这些规则报出的差异只能作为线索，不能当作「违反某条条文」来引用。

还有 2 条规则属于「本机构配置」（PD-004、PD-005）。它们的判据来自配置项而不是国家标准，配置未填时这几条会进入跳过项。

适用场景与同组插件

面向科研管理、基金管理与教研岗的申报与评审材料核对：基金申请书形式审查、试卷解析结构、作文量表评分、政策专报。

同一职业分组「科研教育」下还有 4 个核查插件，分别是量表评分核对（dsh-essay-rubric-check）、能力差距核对（dsh-learning-gap-check）、基金申请书形式审查（dsh-nsfc-form-check）、政策专报核对（dsh-policy-brief-draft）。这几个插件的范围彼此不重叠，也不会互相替代；要覆盖这类材料的全貌，需要挑出对应的几个分别跑。

npm 包名 dsh-paper-doc-adapter，仓库 PerryLink/dsh-paper-doc-adapter，Apache-2.0 许可。页面上的规则与依据由构建脚本从规则库（版本 2026.1）与包的 locale 资源读出，与仓库内容一致。

  • 量表评分核对 dsh-essay-rubric-check —— 作文量表评分核对
  • 能力差距核对 dsh-learning-gap-check —— 能力差距与培养计划核对
  • 基金申请书形式审查 dsh-nsfc-form-check —— 国家自然科学基金申请书形式审查与匿名化提示
  • 政策专报核对 dsh-policy-brief-draft —— 政策专报要素核对

安装

安装分两步——先 add，再确认它进了配置。两条命令都与平台无关，只有过滤输出的写法不同：

bash / sh

dsh plugin --profile default add dsh-paper-doc-adapter
dsh --profile default --dump-config | grep 'dsh-paper-doc-adapter'

PowerShell

dsh plugin --profile default add dsh-paper-doc-adapter
dsh --profile default --dump-config | Select-String 'dsh-paper-doc-adapter'

把 --profile default 换成实际使用的 profile 名。装上之后重新启动会话，插件注册的工具才会出现。
