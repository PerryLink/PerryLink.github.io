这个插件核对什么

量表评分核对（dsh-essay-rubric-check）是一个面向科研教育场景的 DeepSeek Harness 核查插件。作文量表评分核对（按评分项、原文定位与分值算术核对评分自洽，仅提示差异，不作出定性结论）

规则库只有 6 条规则，是本族里最精简的一档；它不追求把材料过一遍，只盯住这类材料上最容易出错的地方。这套规则全部标记为「由原则推导」——逐字条文本次没有取到，所以严重度一律封顶在「提示」，不会有「错误」级结果。

核对方式

核对方式上，量表评分核对主要使用以下几类机械可判定的检查：多字段至少填一（1 条）、字段间关系一致（1 条）、按公式重算并比对（1 条）、条件必填（1 条）、编号或键不得重复（1 条）、表头要素存在性（1 条）。

插件不会替你查证。它只比较材料自身各处之间、以及材料与所引条款之间是否一致；材料里写错的事实，只要内部自洽，就查不出来。

它不作什么判断

这一族插件的立场一致：把材料内部能够逐条指认的差异列出来，合规与否、责任归属、以及能否通过审核，都不由插件给出。每条差异都附上它对照的规则、依据的文件与条款和差异位置，便于逐个复核。

本插件不使用「错误」级严重度，最高只到「提示」：所有规则都只说明「这里与依据不一致」，是否构成问题由人工判断。

规则库中未被命中的规则同样会出现在结果里：无法执行的检查会连同原因一起列出，空的结果列表不等于材料没有问题，只等于规则库覆盖到的那部分没有发现差异。

引用取证状态

引用取证：这套规则库没有任何一条规则可以直接对照逐字条文，全部属于「由原则推导」；其中 6 条在规则库中明确写着条文本次未取得，其余 0 条同样没有条文比对，只是未标记取证状态。

把规则按所引文件归并，得到 2 份依据文件，各自被引用的规则数是：《普通高中语文课程标准》（5 条）、《普通高等学校招生全国统一考试评卷工作规定》（1 条）。同一份文件在不同规则中可能被引用于不同条款。

结果怎么读

本插件共 6 条规则，其中严重度最高的一档是「提示」，共 6 条：ER-001、ER-002、ER-003、ER-004、ER-005、ER-006。这些规则命中时应当优先处理，其余规则的结果可以在其后逐条确认。

另有 6 条规则的条文本次未取得逐字文本（ER-001、ER-002、ER-003、ER-004、ER-005、ER-006）。引用这部分结果时请注意措辞：它们是原则推导的产物，不是条文比对的结果。

适用场景与同组插件

面向科研管理、基金管理与教研岗的申报与评审材料核对：基金申请书形式审查、试卷解析结构、作文量表评分、政策专报。

同一职业分组「科研教育」下还有 4 个核查插件，分别是能力差距核对（dsh-learning-gap-check）、基金申请书形式审查（dsh-nsfc-form-check）、试卷结构核对（dsh-paper-doc-adapter）、政策专报核对（dsh-policy-brief-draft）。这几个插件的范围彼此不重叠，也不会互相替代；要覆盖这类材料的全貌，需要挑出对应的几个分别跑。

npm 包名 dsh-essay-rubric-check，仓库 PerryLink/dsh-essay-rubric-check，Apache-2.0 许可。页面上的规则与依据由构建脚本从规则库（版本 2026.1）与包的 locale 资源读出，与仓库内容一致。

  • 能力差距核对 dsh-learning-gap-check —— 能力差距与培养计划核对
  • 基金申请书形式审查 dsh-nsfc-form-check —— 国家自然科学基金申请书形式审查与匿名化提示
  • 试卷结构核对 dsh-paper-doc-adapter —— 试卷解析结构核对
  • 政策专报核对 dsh-policy-brief-draft —— 政策专报要素核对

安装

安装分两步——先 add，再确认它进了配置。两条命令都与平台无关，只有过滤输出的写法不同：

bash / sh

dsh plugin --profile default add dsh-essay-rubric-check
dsh --profile default --dump-config | grep 'dsh-essay-rubric-check'

PowerShell

dsh plugin --profile default add dsh-essay-rubric-check
dsh --profile default --dump-config | Select-String 'dsh-essay-rubric-check'

上面的 default 是占位，换成你自己的 profile。确认配置里能搜到包名，再重开会话使用。
