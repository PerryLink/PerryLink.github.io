这个插件核对什么

质保索赔核对（dsh-warranty-calc）是一个面向质量制造场景的 DeepSeek Harness 核查插件。质保期与索赔金额核对（按质保期月数与里程、索赔金额算式核对自洽，仅提示差异，不作出定性结论）

7 条规则，是本族里最常见的一档规模，大体对应一次认真的人工通读能看住的范围。依据来源是混合的：「条文直接规定」2 条、「由原则推导」3 条、取自使用机构自身配置 2 条。两类规则的证据强度不同，结果里的严重度已经反映了这个差别。

核对方式

核对方式上，质保索赔核对主要使用以下几类机械可判定的检查：日期可解析（2 条）、多字段至少填一（1 条）、须为可解析数值（1 条）、字段间关系一致（1 条）、乘积关系一致（1 条）、编号或键不得重复（1 条）。

插件不会替你查证。它只比较材料自身各处之间、以及材料与所引条款之间是否一致；材料里写错的事实，只要内部自洽，就查不出来。

它不作什么判断

共同约定只有一条——插件只做「指出不一致」，不做「下结论」。差异清单里每条都带规则编号、依据的文件与条款、以及差异落在材料里的位置。

本插件不产生「错误」级结果，严重度最高为「提示」。它指出的是「此处与依据不一致」，而不是「此处是错的」。

另有 2 条规则的判据来自使用机构自己的配置项，不是国家标准。换机构使用前必须先替换这份配置，否则核对的是别人的口径。

不要把空清单当成结论。规则库够不到的地方、以及因为材料缺少必要字段而无法执行的规则，都会连同原因单列；它们既不算通过，也不算失败。

引用取证状态

引用取证：2 条规则为条文直接规定，且没有任何规则标注条文未取得。其余规则属于「由原则推导」或「本机构配置」，本就不引用条文原文。

被规则引用的文件共 3 份，按引用次数从多到少是：《家用汽车产品修理更换退货责任规定》（5 条）、各厂商质保政策与三包规定（本机构配置）（1 条）、各厂商质保政策（本机构配置）（1 条）。同一份文件在不同规则中可能被引用于不同条款。

结果怎么读

本插件共 7 条规则，其中严重度最高的一档是「提示」，共 5 条：WC-001、WC-003、WC-005、WC-006、WC-007。结果里先看这几条，再回头处理其他规则报出的差异。

还有 2 条规则属于「本机构配置」（WC-002、WC-004）。使用前请确认这几条的配置与本机构口径一致，否则核对的是别人的标准。

适用场景与同组插件

面向质量管理与工艺岗的体系文件核对：FMEA 分析表、PPAP 提交要素、SPC 控制图常数与过程能力、审核意见闭环。

同一职业分组「质量制造」下还有 7 个核查插件，分别是FMEA 表核对（dsh-fmea-table-check）、点评回复核对（dsh-ota-review-check）、项目链条核对（dsh-pipeline-check）、PPAP 要素核对（dsh-ppap-check）、维修工单核对（dsh-repair-order-qc）、审稿回应核对（dsh-review-reply-check） 等。这类材料通常需要同时过几个插件：一个插件只覆盖它自己那份规则库声明过的范围，把几个插件的结果合起来看才是完整的一次复核。

npm 包名 dsh-warranty-calc，仓库 PerryLink/dsh-warranty-calc，Apache-2.0 许可。页面上的规则与依据由构建脚本从规则库（版本 2026.1）与包的 locale 资源读出，与仓库内容一致。

  • FMEA 表核对 dsh-fmea-table-check —— FMEA 分析表要素齐备性与风险顺序数一致性核对
  • 点评回复核对 dsh-ota-review-check —— 在线点评回复台账核对
  • 项目链条核对 dsh-pipeline-check —— 项目全流程文件链条核对
  • PPAP 要素核对 dsh-ppap-check —— PPAP 提交要素齐备性核对
  • 维修工单核对 dsh-repair-order-qc —— 维修工单结算核对
  • 审稿回应核对 dsh-review-reply-check —— 审稿意见逐条回应覆盖核对
  • 控制图常数核对 dsh-spc-gbt-adapter —— 控制图常数与过程能力指数核对

安装

下面是安装命令。两个平台用的都是 dsh，第二行是确认安装结果的写法，按你所在的 shell 选一条：

bash / sh

dsh plugin --profile default add dsh-warranty-calc
dsh --profile default --dump-config | grep 'dsh-warranty-calc'

PowerShell

dsh plugin --profile default add dsh-warranty-calc
dsh --profile default --dump-config | Select-String 'dsh-warranty-calc'

若你用的不是 default profile，把名字替换掉即可。安装后需要重启会话，工具才会注册进来。
