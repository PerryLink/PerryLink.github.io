这个插件核对什么

公文格式核对（dsh-gongwen-word-check）是一个面向公文档案场景的 DeepSeek Harness 核查插件。公文格式要素核对（按公开的党政机关公文格式标准核对版头与主体要素，仅提示差异，不作出定性结论）

规则库 7 条规则，数量居中：既能覆盖这类材料的主要要素，又不会把无关项也拉进来。规则库的依据类型分布是 由原则推导 6 条、本机构配置 1 条。

核对方式

核对方式上，公文格式核对主要使用以下几类机械可判定的检查：。

整个核对是封闭的：只看材料里写了什么，不去查任何外部数据源，也不让模型发表意见。这意味着结果可复现，也意味着无法核对材料之外的事实。

需要说明的是，该规则库不做任何数值运算，核对的是要素是否齐备、取值是否在允许范围内、字段之间的关系是否自洽。

它不作什么判断

本族插件的共同约定是：只列出材料内部可以逐条指认的差异，不判定合规、不认定责任、不替代主管部门或审核人的结论。报告里每一条差异都会带上它对照的规则、依据的文件与条款，以及差异的具体位置。

本插件不产生「错误」级结果，严重度最高为「提示」。它指出的是「此处与依据不一致」，而不是「此处是错的」。

另有 1 条规则的判据来自使用机构自己的配置项，不是国家标准。换机构使用前必须先替换这份配置，否则核对的是别人的口径。

规则库中未被命中的规则同样会出现在结果里：无法执行的检查会连同原因一起列出，空的结果列表不等于材料没有问题，只等于规则库覆盖到的那部分没有发现差异。

严重度含义：提示（6 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（1 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：由原则推导（6 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」；本机构配置（1 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」。

引用取证状态

引用取证：7 条规则全部为「由原则推导」，没有一条声称依据了逐字条文。其中 5 条如实标注「本次未取得」。这意味着结果里的每一条差异都只能作为线索，不能作为「违反某条条文」的结论。

被规则引用的文件共 2 份，按引用次数从多到少是：《党政机关公文格式》（5 条）、《党政机关公文处理工作条例》（2 条）。引用数统计到文件一层；同一文件内的不同条款可能分别支撑不同规则。

结果怎么读

本插件共 7 条规则，其中严重度最高的一档是「提示」，共 6 条：GW-001、GW-002、GW-004、GW-005、GW-006、GW-007。这几条是清单里最需要先看的；其余条目按材料实际内容逐条判断即可。

另有 5 条规则的条文本次未取得逐字文本（GW-001、GW-002、GW-004、GW-005、GW-007）。引用这部分结果时请注意措辞：它们是原则推导的产物，不是条文比对的结果。

还有 1 条规则属于「本机构配置」（GW-003）。它们的判据来自配置项而不是国家标准，配置未填时这几条会进入跳过项。

适用场景与同组插件

面向办公室、文秘与档案室的公文与归档核对：公文格式要素、文种与发文字号、流转时限、归档完整性与保管期限。

同一职业分组「公文档案」下还有 2 个核查插件，分别是档案归档核对（dsh-archive-check）、公文流转核对（dsh-gongwen-flow-check）。这类材料通常需要同时过几个插件：一个插件只覆盖它自己那份规则库声明过的范围，把几个插件的结果合起来看才是完整的一次复核。

该插件以 npm 包 dsh-gongwen-word-check 发布，仓库在 GitHub 的 PerryLink/dsh-gongwen-word-check，采用 Apache-2.0 许可。本页内容由构建脚本从插件自身的规则库与 locale 资源生成，与仓库中的规则库版本 2026.1 对应。

  • 档案归档核对 dsh-archive-check —— 档案归档完整性与保管期限核对
  • 公文流转核对 dsh-gongwen-flow-check —— 公文流转与办理时限核对

安装

先在 bash 或 PowerShell 里装上，再确认配置里出现了这个包名：

bash / sh

dsh plugin --profile default add dsh-gongwen-word-check
dsh --profile default --dump-config | grep 'dsh-gongwen-word-check'

PowerShell

dsh plugin --profile default add dsh-gongwen-word-check
dsh --profile default --dump-config | Select-String 'dsh-gongwen-word-check'

把 --profile default 换成实际使用的 profile 名。装上之后重新启动会话，插件注册的工具才会出现。
