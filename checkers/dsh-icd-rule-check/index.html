这个插件核对什么

ICD 编码规则校验（dsh-icd-rule-check）是一个面向医疗病案场景的 DeepSeek Harness 核查插件。ICD 合并编码与星剑号配对提示（依据 GB/T 14396-2016 与公开的 ICD 使用说明，仅提示差异，不作出定性结论）

规则库共 12 条规则，是本族中规则较多的一档，逐项核对下来基本等于把这类材料完整过一遍。这 12 条规则里，6 条有逐字条文支撑，4 条只能由原则推导，2 条的依据是本机构配置。

核对方式

从检查方式看，ICD 编码规则校验用的是几类可以机械判定的手段：。

所有检查都只在材料内部完成——不连外部数据库、不联网、不请模型裁决，所以同一份材料在相同配置下重复跑，结果逐字相同。

这里没有算术核对——规则库处理的是齐备性、取值合法性与字段关系，不重算任何金额或数量。

它不作什么判断

把它当成一次机械的交叉核对，而不是一次评审。核对结果里不会出现「合规」「不合格」这类字样，只有「此处与所引依据不一致」以及不一致的具体位置。

本插件使用「错误」级严重度，共 5 条规则属于该级。这些规则所依据的条文都已取得逐字文本，只有在材料与条文明确不符时才会命中，也因此可以作为返工依据。

需要注意 2 条「本机构配置」类规则：它们的阈值与清单由使用机构自己填入，插件不自带。配置为空时这些规则不会执行，而是把自己列进跳过项。

没被命中的规则不会被悄悄丢掉：凡是没能执行的检查都会连同原因一并列出。因此结果为空只说明规则库覆盖到的范围内没发现差异，不能读成「材料没问题」。

严重度含义：错误（5 条）——规则所依据的条文已取得逐字文本，出现差异即为明确不符；提示（4 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（3 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：条文直接规定（6 条）——该规则的依据条文已取得逐字文本，规则直接对照条文规定；由原则推导（4 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」；本机构配置（2 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」。

引用取证状态

引用取证：规则库没有遗留待取证条目。6 条规则直接对照条文；剩下的规则依据原则或本机构配置，不涉及条文原文，因此不存在取证进度问题。

规则引用的文件共 3 份，按引用规则数排列为：《住院病案首页数据填写质量规范（暂行）》（8 条）、《医疗保障基金结算清单填写规范（试行）》（3 条）、《疾病和有关健康问题的国际统计分类》第十次修订本 第二卷 指导手册（1 条）。同一文件的不同条款会被多条规则分别引用，因此上面是文件层面的汇总。

结果怎么读

本插件共 12 条规则，其中严重度最高的一档是「错误」，共 5 条：IC-001、IC-003、IC-011、IC-007、IC-009。这几条是清单里最需要先看的；其余条目按材料实际内容逐条判断即可。

还有 2 条规则属于「本机构配置」（IC-004、IC-010）。这几条只有在配置被填写后才会执行；未配置时它们不会静默通过，而是列入跳过。

适用场景与同组插件

面向病案室、质控科与临床科室的病历与编码核对：病案首页、护理记录、ICD 编码结构与星剑号配对。

同一职业分组「医疗病案」下还有 2 个核查插件，分别是病案首页质控（dsh-medrec-qc）、护理记录时限、签名与评估表完整性校验（dsh-nurse-record-check）。实际使用中往往要跑不止一个：单个插件只负责它自己那份规则库声明过的范围，范围之间不重叠，合起来才接近一次完整复核。

该插件以 npm 包 dsh-icd-rule-check 发布，仓库在 GitHub 的 PerryLink/dsh-icd-rule-check，采用 Apache-2.0 许可。本页内容由构建脚本从插件自身的规则库与 locale 资源生成，与仓库中的规则库版本 2026.1 对应。

  • 病案首页质控 dsh-medrec-qc —— 病案首页形式质控与逻辑矛盾提示
  • 护理记录时限、签名与评估表完整性校验 dsh-nurse-record-check —— 护理记录时限、签名与评估表完整性校验

安装

下面是安装命令。两个平台用的都是 dsh，第二行是确认安装结果的写法，按你所在的 shell 选一条：

bash / sh

dsh plugin --profile default add dsh-icd-rule-check
dsh --profile default --dump-config | grep 'dsh-icd-rule-check'

PowerShell

dsh plugin --profile default add dsh-icd-rule-check
dsh --profile default --dump-config | Select-String 'dsh-icd-rule-check'

若你用的不是 default profile，把名字替换掉即可。安装后需要重启会话，工具才会注册进来。
