这个插件核对什么

PPAP 要素核对（dsh-ppap-check）是一个面向质量制造场景的 DeepSeek Harness 核查插件。PPAP 提交要素齐备性核对（按公开的 PPAP 手册与提交等级核对要素齐备与版本填写，仅提示差异，不作出定性结论）

规则库 7 条规则，数量居中：既能覆盖这类材料的主要要素，又不会把无关项也拉进来。该规则库的规则依据构成为：由原则推导 6 条、本机构配置 1 条。

核对方式

PPAP 要素核对的检查手段集中在以下几类，都不依赖模型判断：。

检查过程不引入任何外部信息：没有数据库查询、没有网络请求、没有模型参与，同样输入必然得到同样输出。

需要说明的是，该规则库不做任何数值运算，核对的是要素是否齐备、取值是否在允许范围内、字段之间的关系是否自洽。

它不作什么判断

本族插件的共同约定是：只列出材料内部可以逐条指认的差异，不判定合规、不认定责任、不替代主管部门或审核人的结论。报告里每一条差异都会带上它对照的规则、依据的文件与条款，以及差异的具体位置。

这个插件不会说某处「错了」。它最高只标到「提示」级，含义是「此处与所引依据对不上，请确认」。

其中 1 条规则的阈值或清单来自使用机构自身配置，而不是国家标准。这类规则在更换机构后必须先改配置再使用，否则会拿别的机构的口径核对本机构的材料。

结果里的空清单有明确含义，插件对此不作暗示：规则库覆盖不到的部分、以及因缺少必要字段而无法执行的检查，都会单独列出原因。

严重度含义：提示（6 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（1 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：由原则推导（6 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」；本机构配置（1 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」。

结果怎么读

本插件共 7 条规则，其中严重度最高的一档是「提示」，共 6 条：PP-001、PP-002、PP-003、PP-004、PP-006、PP-007。这几条是清单里最需要先看的；其余条目按材料实际内容逐条判断即可。

另有 7 条规则的条文本次未取得逐字文本（PP-001、PP-002、PP-003、PP-004、PP-005、PP-006、PP-007）。这些规则报出的差异只能作为线索，不能当作「违反某条条文」来引用。

还有 1 条规则属于「本机构配置」（PP-005）。这几条只有在配置被填写后才会执行；未配置时它们不会静默通过，而是列入跳过。

适用场景与同组插件

面向质量管理与工艺岗的体系文件核对：FMEA 分析表、PPAP 提交要素、SPC 控制图常数与过程能力、审核意见闭环。

同一职业分组「质量制造」下还有 7 个核查插件，分别是FMEA 表核对（dsh-fmea-table-check）、点评回复核对（dsh-ota-review-check）、项目链条核对（dsh-pipeline-check）、维修工单核对（dsh-repair-order-qc）、审稿回应核对（dsh-review-reply-check）、控制图常数核对（dsh-spc-gbt-adapter） 等。实际使用中往往要跑不止一个：单个插件只负责它自己那份规则库声明过的范围，范围之间不重叠，合起来才接近一次完整复核。

该插件以 npm 包 dsh-ppap-check 发布，仓库在 GitHub 的 PerryLink/dsh-ppap-check，采用 Apache-2.0 许可。本页内容由构建脚本从插件自身的规则库与 locale 资源生成，与仓库中的规则库版本 2026.1 对应。

  • FMEA 表核对 dsh-fmea-table-check —— FMEA 分析表要素齐备性与风险顺序数一致性核对
  • 点评回复核对 dsh-ota-review-check —— 在线点评回复台账核对
  • 项目链条核对 dsh-pipeline-check —— 项目全流程文件链条核对
  • 维修工单核对 dsh-repair-order-qc —— 维修工单结算核对
  • 审稿回应核对 dsh-review-reply-check —— 审稿意见逐条回应覆盖核对
  • 控制图常数核对 dsh-spc-gbt-adapter —— 控制图常数与过程能力指数核对
  • 质保索赔核对 dsh-warranty-calc —— 质保期与索赔金额核对

安装

安装分两步——先 add，再确认它进了配置。两条命令都与平台无关，只有过滤输出的写法不同：

bash / sh

dsh plugin --profile default add dsh-ppap-check
dsh --profile default --dump-config | grep 'dsh-ppap-check'

PowerShell

dsh plugin --profile default add dsh-ppap-check
dsh --profile default --dump-config | Select-String 'dsh-ppap-check'

若你用的不是 default profile，把名字替换掉即可。安装后需要重启会话，工具才会注册进来。
