这个插件核对什么

许可办理核对（dsh-permit-report-check）是一个面向工程建设场景的 DeepSeek Harness 核查插件。行政许可办理核对（按申请材料、法定时限与决定记录核对台账闭环，仅提示差异，不作出定性结论）

规则库共 7 条规则，覆盖面与人工复核一遍的注意力分配大致相当。该规则库的规则依据构成为：由原则推导 5 条、本机构配置 2 条。

核对方式

从检查方式看，许可办理核对用的是几类可以机械判定的手段：条件必填（2 条）、日期可解析（2 条）、取值须在允许清单内（1 条）、表头要素存在性（1 条）、编号或键不得重复（1 条）。

这些检查都只读取材料本身的内容：不查外部数据库、不做联网核对、不调用模型判断，因此同一份材料在同样配置下每次得到的结果一致。

这里没有算术核对——规则库处理的是齐备性、取值合法性与字段关系，不重算任何金额或数量。

它不作什么判断

这个插件不提供结论，只提供线索：材料内部可以逐条指认的不一致会被列出来，每条都标明它对照的规则、依据的文件与条款、以及差异在材料中的位置。是否构成问题、是否需要整改，由看到这份清单的人判断。

这个插件不会说某处「错了」。它最高只标到「提示」级，含义是「此处与所引依据对不上，请确认」。

其中 2 条规则的阈值或清单来自使用机构自身配置，而不是国家标准。这类规则在更换机构后必须先改配置再使用，否则会拿别的机构的口径核对本机构的材料。

结果里的空清单有明确含义，插件对此不作暗示：规则库覆盖不到的部分、以及因缺少必要字段而无法执行的检查，都会单独列出原因。

严重度含义：提示（5 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（2 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：由原则推导（5 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」；本机构配置（2 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」。

这是引用取证记录中的完整编号与效力说明，含发布日期、实施日期、代替关系与强制性说明。规则库核对时对照的是这里列出的版本；若本单位执行的是其他版本，结论不直接适用。

这是插件声明的依据清单。要注意它是文件层面的：每条规则实际对照的是文件中的某个具体条款，取证进度按条款记录。

引用取证状态

引用取证：7 条规则全部为「由原则推导」，没有一条声称依据了逐字条文。其中 5 条如实标注「本次未取得」。这意味着结果里的每一条差异都只能作为线索，不能作为「违反某条条文」的结论。

规则库落在 3 份文件上，分布如下：《中华人民共和国行政许可法》（5 条）、各事项办事指南与承诺时限（本机构配置）（1 条）、本机构许可办理管理口径（本机构配置）（1 条）。同一份文件在不同规则中可能被引用于不同条款。

结果怎么读

本插件共 7 条规则，其中严重度最高的一档是「提示」，共 5 条：PR-001、PR-002、PR-005、PR-006、PR-007。这几条是清单里最需要先看的；其余条目按材料实际内容逐条判断即可。

另有 5 条规则的条文本次未取得逐字文本（PR-001、PR-002、PR-005、PR-006、PR-007）。引用这部分结果时请注意措辞：它们是原则推导的产物，不是条文比对的结果。

还有 2 条规则属于「本机构配置」（PR-003、PR-004）。它们的判据来自配置项而不是国家标准，配置未填时这几条会进入跳过项。

适用场景与同组插件

面向施工、监理与建设单位的现场与报批文件核对：安全技术交底、监理日志、危大工程、环评导则、土壤与地下水监测。

同一职业分组「工程建设」下还有 6 个核查插件，分别是环评导则核对（dsh-eia-guide-check）、防护用品配置核对（dsh-guard-plan-qc）、HAZOP 分析表核对（dsh-hazplan-check）、安全技术交底核对（dsh-safety-brief-check）、监理日志校验（dsh-site-log-check）、土壤地下水监测核对（dsh-soilwater-check）。这几个插件的范围彼此不重叠，也不会互相替代；要覆盖这类材料的全貌，需要挑出对应的几个分别跑。

发布渠道是 npm 包 dsh-permit-report-check，源码在 GitHub 的 PerryLink/dsh-permit-report-check，许可为 Apache-2.0。本页的规则清单直接取自仓库里的规则库文件（版本 2026.1），不是手写的介绍。

  • 环评导则核对 dsh-eia-guide-check —— 环评导则适用性核对
  • 防护用品配置核对 dsh-guard-plan-qc —— 劳动保护与安全防护用品配置表核对
  • HAZOP 分析表核对 dsh-hazplan-check —— HAZOP 分析表要素齐备性与偏差推导一致性核对
  • 安全技术交底核对 dsh-safety-brief-check —— 安全技术交底记录要素齐备性与签字闭环核对
  • 监理日志校验 dsh-site-log-check —— 监理日志跨日连续性与旁站覆盖提示
  • 土壤地下水监测核对 dsh-soilwater-check —— 土壤与地下水监测台账核对

安装

安装命令对两个平台是同一个 dsh 子命令，只有随后确认安装结果的那一步按 shell 不同：

bash / sh

dsh plugin --profile default add dsh-permit-report-check
dsh --profile default --dump-config | grep 'dsh-permit-report-check'

PowerShell

dsh plugin --profile default add dsh-permit-report-check
dsh --profile default --dump-config | Select-String 'dsh-permit-report-check'

profile 名按实际情况替换。注意安装本身不会热加载——重开会话之后插件才生效。
