这个插件核对什么

质疑投诉期限核对（dsh-protest-deadline）是一个面向招投标场景的 DeepSeek Harness 核查插件。质疑与投诉期限核对（按公开的政府采购质疑投诉规定核对期限与台账自洽，仅提示差异，不作出定性结论）

规则库共 7 条规则，覆盖面与人工复核一遍的注意力分配大致相当。该规则库同时包含「条文直接规定」与「由原则推导」两类依据：前者 3 条，后者 2 条，另有 2 条取自使用机构自身配置。

核对方式

质疑投诉期限核对的检查手段集中在以下几类，都不依赖模型判断：。

这些检查都只读取材料本身的内容：不查外部数据库、不做联网核对、不调用模型判断，因此同一份材料在同样配置下每次得到的结果一致。

该规则库不涉及数值计算：它看的是要素齐不齐、取值在不在允许范围内、字段之间对不对得上。

它不作什么判断

共同约定只有一条——插件只做「指出不一致」，不做「下结论」。差异清单里每条都带规则编号、依据的文件与条款、以及差异落在材料里的位置。

本插件不产生「错误」级结果，严重度最高为「提示」。它指出的是「此处与依据不一致」，而不是「此处是错的」。

其中 2 条规则的阈值或清单来自使用机构自身配置，而不是国家标准。这类规则在更换机构后必须先改配置再使用，否则会拿别的机构的口径核对本机构的材料。

每个没能跑起来的检查都会出现在跳过项里并附上原因——缺字段、缺配置、或规则要求的前置项不存在。所以「没有差异」和「没有检查」在结果里是两件分开陈述的事。

严重度含义：提示（5 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（2 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：条文直接规定（3 条）——该规则的依据条文已取得逐字文本，规则直接对照条文规定；本机构配置（2 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」；由原则推导（2 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」。

结果怎么读

本插件共 7 条规则，其中严重度最高的一档是「提示」，共 5 条：PD-001、PD-002、PD-004、PD-006、PD-007。这几条是清单里最需要先看的；其余条目按材料实际内容逐条判断即可。

还有 2 条规则属于「本机构配置」（PD-003、PD-005）。这几条只有在配置被填写后才会执行；未配置时它们不会静默通过，而是列入跳过。

适用场景与同组插件

面向招标人、招标代理与投标人的文件级核对：投标文件符合性、投标人资格、评标因素评分矩阵、质疑与投诉期限。

同一职业分组「招投标」下还有 6 个核查插件，分别是投标符合性预检（dsh-bid-ca-precheck）、资格条件核对（dsh-bid-qual-check）、合同立场核对（dsh-contract-stance）、规则库自检（dsh-rulefile-check）、招标条款摘录核对（dsh-tender-extract）、评分矩阵核对（dsh-tender-matrix）。这几个插件的范围彼此不重叠，也不会互相替代；要覆盖这类材料的全貌，需要挑出对应的几个分别跑。

发布渠道是 npm 包 dsh-protest-deadline，源码在 GitHub 的 PerryLink/dsh-protest-deadline，许可为 Apache-2.0。本页的规则清单直接取自仓库里的规则库文件（版本 2026.1），不是手写的介绍。

  • 投标符合性预检 dsh-bid-ca-precheck —— 投标文件符合性预检
  • 资格条件核对 dsh-bid-qual-check —— 投标人资格条件核对
  • 合同立场核对 dsh-contract-stance —— 合同条款立场台账核对
  • 规则库自检 dsh-rulefile-check —— 规则库文件自检核对
  • 招标条款摘录核对 dsh-tender-extract —— 招标文件条款摘录核对
  • 评分矩阵核对 dsh-tender-matrix —— 评标因素评分矩阵核对

安装

插件通过 dsh plugin add 安装，两条命令的主体一致，区别只在装完后用什么方式确认它已经注册：

bash / sh

dsh plugin --profile default add dsh-protest-deadline
dsh --profile default --dump-config | grep 'dsh-protest-deadline'

PowerShell

dsh plugin --profile default add dsh-protest-deadline
dsh --profile default --dump-config | Select-String 'dsh-protest-deadline'

上面的 default 是占位，换成你自己的 profile。确认配置里能搜到包名，再重开会话使用。
