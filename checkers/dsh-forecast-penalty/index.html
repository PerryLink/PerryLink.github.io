这个插件核对什么

预测考核核对（dsh-forecast-penalty）是一个面向关务外贸场景的 DeepSeek Harness 核查插件。预测准确率考核核对（按准确率、门槛与考核单价核对考核费用的算术自洽，仅提示差异，不作出定性结论）

7 条规则，是本族里最常见的一档规模，大体对应一次认真的人工通读能看住的范围。该规则库的规则依据构成为：由原则推导 5 条、本机构配置 2 条。

核对方式

从检查方式看，预测考核核对用的是几类可以机械判定的手段：。

检查过程不引入任何外部信息：没有数据库查询、没有网络请求、没有模型参与，同样输入必然得到同样输出。

该规则库不涉及数值计算：它看的是要素齐不齐、取值在不在允许范围内、字段之间对不对得上。

它不作什么判断

把它当成一次机械的交叉核对，而不是一次评审。核对结果里不会出现「合规」「不合格」这类字样，只有「此处与所引依据不一致」以及不一致的具体位置。

本插件不使用「错误」级严重度，最高只到「提示」：所有规则都只说明「这里与依据不一致」，是否构成问题由人工判断。

其中 2 条规则的阈值或清单来自使用机构自身配置，而不是国家标准。这类规则在更换机构后必须先改配置再使用，否则会拿别的机构的口径核对本机构的材料。

规则库中未被命中的规则同样会出现在结果里：无法执行的检查会连同原因一起列出，空的结果列表不等于材料没有问题，只等于规则库覆盖到的那部分没有发现差异。

引用取证状态

引用取证：7 条规则全部为「由原则推导」，没有一条声称依据了逐字条文。其中 1 条如实标注「本次未取得」。这意味着结果里的每一条差异都只能作为线索，不能作为「违反某条条文」的结论。

把规则按所引文件归并，得到 2 份依据文件，各自被引用的规则数是：电力市场考核办法与并网调度协议（无国家标准）（6 条）、《表示货币的代码》（1 条）。同一文件的不同条款会被多条规则分别引用，因此上面是文件层面的汇总。

结果怎么读

本插件共 7 条规则，其中严重度最高的一档是「提示」，共 5 条：FP-001、FP-002、FP-005、FP-006、FP-007。结果里先看这几条，再回头处理其他规则报出的差异。

另有 1 条规则的条文本次未取得逐字文本（FP-005）。这些规则报出的差异只能作为线索，不能当作「违反某条条文」来引用。

还有 2 条规则属于「本机构配置」（FP-003、FP-004）。它们的判据来自配置项而不是国家标准，配置未填时这几条会进入跳过项。

适用场景与同组插件

面向报关、单证与供应链合规岗的关务核对：报关单证一致、商品归类层级、原产地 RVC、出口管制、信用证与滞箱费台账。

同一职业分组「关务外贸」下还有 7 个核查插件，分别是报关单证核对（dsh-customs-doc-check）、滞箱费台账核对（dsh-demurrage-ledger）、出口管制核对（dsh-export-ctl-check）、归类层级核对（dsh-hs-classify）、信用证单据核对（dsh-lc-doc-check）、原产地 RVC 核对（dsh-origin-rvc-check） 等。这几个插件的范围彼此不重叠，也不会互相替代；要覆盖这类材料的全貌，需要挑出对应的几个分别跑。

npm 包名 dsh-forecast-penalty，仓库 PerryLink/dsh-forecast-penalty，Apache-2.0 许可。页面上的规则与依据由构建脚本从规则库（版本 2026.1）与包的 locale 资源读出，与仓库内容一致。

  • 报关单证核对 dsh-customs-doc-check —— 报关单证一致性核对
  • 滞箱费台账核对 dsh-demurrage-ledger —— 滞箱费台账核对
  • 出口管制核对 dsh-export-ctl-check —— 出口管制物项核对
  • 归类层级核对 dsh-hs-classify —— 商品归类层级一致性核对
  • 信用证单据核对 dsh-lc-doc-check —— 信用证单据条款核对
  • 原产地 RVC 核对 dsh-origin-rvc-check —— 原产地区域价值成分核对
  • 施工天窗核对 dsh-railway-window —— 铁路施工天窗台账核对

安装

安装分两步——先 add，再确认它进了配置。两条命令都与平台无关，只有过滤输出的写法不同：

bash / sh

dsh plugin --profile default add dsh-forecast-penalty
dsh --profile default --dump-config | grep 'dsh-forecast-penalty'

PowerShell

dsh plugin --profile default add dsh-forecast-penalty
dsh --profile default --dump-config | Select-String 'dsh-forecast-penalty'

把 --profile default 换成实际使用的 profile 名。装上之后重新启动会话，插件注册的工具才会出现。
