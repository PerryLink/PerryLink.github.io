这个插件核对什么

环评导则核对（dsh-eia-guide-check）是一个面向工程建设场景的 DeepSeek Harness 核查插件。环评导则适用性核对（按要素、导则名称与执行标准核对台账自洽，仅提示差异，不作出定性结论）

7 条规则，是本族里最常见的一档规模，大体对应一次认真的人工通读能看住的范围。规则库的依据类型分布是 由原则推导 6 条、本机构配置 1 条。

核对方式

核对方式上，环评导则核对主要使用以下几类机械可判定的检查：多字段至少填一（2 条）、格式须匹配规定形式（1 条）、取值须在允许清单内（1 条）、编号或键不得重复（1 条）、表头要素存在性（1 条）、须包含给定要素之一（1 条）。

所有检查都只在材料内部完成——不连外部数据库、不联网、不请模型裁决，所以同一份材料在相同配置下重复跑，结果逐字相同。

需要说明的是，该规则库不做任何数值运算，核对的是要素是否齐备、取值是否在允许范围内、字段之间的关系是否自洽。

它不作什么判断

把它当成一次机械的交叉核对，而不是一次评审。核对结果里不会出现「合规」「不合格」这类字样，只有「此处与所引依据不一致」以及不一致的具体位置。

本插件不使用「错误」级严重度，最高只到「提示」：所有规则都只说明「这里与依据不一致」，是否构成问题由人工判断。

需要注意 1 条「本机构配置」类规则：它们的阈值与清单由使用机构自己填入，插件不自带。配置为空时这些规则不会执行，而是把自己列进跳过项。

规则库中未被命中的规则同样会出现在结果里：无法执行的检查会连同原因一起列出，空的结果列表不等于材料没有问题，只等于规则库覆盖到的那部分没有发现差异。

严重度含义：提示（6 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（1 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：由原则推导（6 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」；本机构配置（1 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」。

这是引用取证记录中的完整编号与效力说明，含发布日期、实施日期、代替关系与强制性说明。规则库核对时对照的是这里列出的版本；若本单位执行的是其他版本，结论不直接适用。

这是插件声明的依据清单。要注意它是文件层面的：每条规则实际对照的是文件中的某个具体条款，取证进度按条款记录。

引用取证状态

引用取证：7 条规则全部为「由原则推导」，没有一条声称依据了逐字条文。其中 7 条如实标注「本次未取得」。这意味着结果里的每一条差异都只能作为线索，不能作为「违反某条条文」的结论。

被规则引用的文件共 4 份，按引用次数从多到少是：《环境影响评价技术导则 总纲》（3 条）、《环境影响评价技术导则》系列（2 条）、本机构环评质量管理口径（本机构配置）（1 条）、《建设项目环境影响评价分类管理名录》（1 条）。引用数统计到文件一层；同一文件内的不同条款可能分别支撑不同规则。

结果怎么读

本插件共 7 条规则，其中严重度最高的一档是「提示」，共 6 条：EG-001、EG-002、EG-004、EG-005、EG-006、EG-007。结果里先看这几条，再回头处理其他规则报出的差异。

另有 7 条规则的条文本次未取得逐字文本（EG-001、EG-002、EG-003、EG-004、EG-005、EG-006、EG-007）。这些规则报出的差异只能作为线索，不能当作「违反某条条文」来引用。

还有 1 条规则属于「本机构配置」（EG-003）。使用前请确认这几条的配置与本机构口径一致，否则核对的是别人的标准。

适用场景与同组插件

面向施工、监理与建设单位的现场与报批文件核对：安全技术交底、监理日志、危大工程、环评导则、土壤与地下水监测。

同一职业分组「工程建设」下还有 6 个核查插件，分别是防护用品配置核对（dsh-guard-plan-qc）、HAZOP 分析表核对（dsh-hazplan-check）、许可办理核对（dsh-permit-report-check）、安全技术交底核对（dsh-safety-brief-check）、监理日志校验（dsh-site-log-check）、土壤地下水监测核对（dsh-soilwater-check）。这几个插件的范围彼此不重叠，也不会互相替代；要覆盖这类材料的全貌，需要挑出对应的几个分别跑。

  • 许可办理核对 dsh-permit-report-check —— 行政许可办理核对
  • 安全技术交底核对 dsh-safety-brief-check —— 安全技术交底记录要素齐备性与签字闭环核对
  • 监理日志校验 dsh-site-log-check —— 监理日志跨日连续性与旁站覆盖提示
  • 土壤地下水监测核对 dsh-soilwater-check —— 土壤与地下水监测台账核对

安装

插件通过 dsh plugin add 安装，两条命令的主体一致，区别只在装完后用什么方式确认它已经注册：

bash / sh

dsh plugin --profile default add dsh-eia-guide-check
dsh --profile default --dump-config | grep 'dsh-eia-guide-check'

PowerShell

dsh plugin --profile default add dsh-eia-guide-check
dsh --profile default --dump-config | Select-String 'dsh-eia-guide-check'

profile 名按实际情况替换。注意安装本身不会热加载——重开会话之后插件才生效。
