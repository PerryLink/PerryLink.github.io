这个插件核对什么

政策专报核对（dsh-policy-brief-draft）是一个面向科研教育场景的 DeepSeek Harness 核查插件。政策专报要素核对（按观点、依据、出处与建议核对专报齐备，仅提示差异，不作出定性结论）

规则库 8 条规则，数量居中：既能覆盖这类材料的主要要素，又不会把无关项也拉进来。规则库中没有任何一条声称自己依据了逐字条文：全部为「由原则推导」，最高严重度因此只到「提示」。

核对方式

核对方式上，政策专报核对主要使用以下几类机械可判定的检查：必填项存在性（3 条）、日期不得晚于给定基准（1 条）、数据时效（1 条）、条件必填（1 条）、表头要素存在性（1 条）、编号或键不得重复（1 条）。

所有检查都只在材料内部完成——不连外部数据库、不联网、不请模型裁决，所以同一份材料在相同配置下重复跑，结果逐字相同。

这里没有算术核对——规则库处理的是齐备性、取值合法性与字段关系，不重算任何金额或数量。

它不作什么判断

这个插件不提供结论，只提供线索：材料内部可以逐条指认的不一致会被列出来，每条都标明它对照的规则、依据的文件与条款、以及差异在材料中的位置。是否构成问题、是否需要整改，由看到这份清单的人判断。

这个插件不会说某处「错了」。它最高只标到「提示」级，含义是「此处与所引依据对不上，请确认」。

没被命中的规则不会被悄悄丢掉：凡是没能执行的检查都会连同原因一并列出。因此结果为空只说明规则库覆盖到的范围内没发现差异，不能读成「材料没问题」。

引用取证状态

引用取证：8 条规则全部为「由原则推导」，没有一条声称依据了逐字条文。其中 8 条如实标注「本次未取得」。这意味着结果里的每一条差异都只能作为线索，不能作为「违反某条条文」的结论。

规则引用的文件共 1 份，按引用规则数排列为：《党政机关公文处理工作条例》（8 条）。同一份文件在不同规则中可能被引用于不同条款。

结果怎么读

本插件共 8 条规则，其中严重度最高的一档是「提示」，共 7 条：PB-001、PB-002、PB-003、PB-004、PB-006、PB-007、PB-008。这些规则命中时应当优先处理，其余规则的结果可以在其后逐条确认。

另有 8 条规则的条文本次未取得逐字文本（PB-001、PB-002、PB-003、PB-004、PB-005、PB-006、PB-007、PB-008）。这几条的结果适合作为自查提示，若要对外引用，需要先自行补齐条文原文。

适用场景与同组插件

面向科研管理、基金管理与教研岗的申报与评审材料核对：基金申请书形式审查、试卷解析结构、作文量表评分、政策专报。

同一职业分组「科研教育」下还有 4 个核查插件，分别是量表评分核对（dsh-essay-rubric-check）、能力差距核对（dsh-learning-gap-check）、基金申请书形式审查（dsh-nsfc-form-check）、试卷结构核对（dsh-paper-doc-adapter）。这类材料通常需要同时过几个插件：一个插件只覆盖它自己那份规则库声明过的范围，把几个插件的结果合起来看才是完整的一次复核。

发布渠道是 npm 包 dsh-policy-brief-draft，源码在 GitHub 的 PerryLink/dsh-policy-brief-draft，许可为 Apache-2.0。本页的规则清单直接取自仓库里的规则库文件（版本 2026.1），不是手写的介绍。

  • 量表评分核对 dsh-essay-rubric-check —— 作文量表评分核对
  • 能力差距核对 dsh-learning-gap-check —— 能力差距与培养计划核对
  • 基金申请书形式审查 dsh-nsfc-form-check —— 国家自然科学基金申请书形式审查与匿名化提示
  • 试卷结构核对 dsh-paper-doc-adapter —— 试卷解析结构核对

安装

插件通过 dsh plugin add 安装，两条命令的主体一致，区别只在装完后用什么方式确认它已经注册：

bash / sh

dsh plugin --profile default add dsh-policy-brief-draft
dsh --profile default --dump-config | grep 'dsh-policy-brief-draft'

PowerShell

dsh plugin --profile default add dsh-policy-brief-draft
dsh --profile default --dump-config | Select-String 'dsh-policy-brief-draft'

把 --profile default 换成实际使用的 profile 名。装上之后重新启动会话，插件注册的工具才会出现。
