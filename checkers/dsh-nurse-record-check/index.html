这个插件核对什么

护理记录时限、签名与评估表完整性校验（dsh-nurse-record-check）是一个面向医疗病案场景的 DeepSeek Harness 核查插件。护理记录时限、签名与评估表完整性校验（依据《病历书写基本规范》等公开文件，仅提示差异，不作出定性结论）

12 条规则构成了本族里较完整的一套核对，落到的要素比多数插件更多。依据来源是混合的：「条文直接规定」8 条、「由原则推导」2 条、取自使用机构自身配置 2 条。两类规则的证据强度不同，结果里的严重度已经反映了这个差别。

检查过程不引入任何外部信息：没有数据库查询、没有网络请求、没有模型参与，同样输入必然得到同样输出。

需要说明的是，该规则库不做任何数值运算，核对的是要素是否齐备、取值是否在允许范围内、字段之间的关系是否自洽。

它不作什么判断

本族插件的共同约定是：只列出材料内部可以逐条指认的差异，不判定合规、不认定责任、不替代主管部门或审核人的结论。报告里每一条差异都会带上它对照的规则、依据的文件与条款，以及差异的具体位置。

与其他插件不同，本插件会给出「错误」级结果：7 条规则属于该级。这一级只在规则所依据的条文已取得逐字文本时使用，命中即表示材料与条文明确不符。

需要注意 2 条「本机构配置」类规则：它们的阈值与清单由使用机构自己填入，插件不自带。配置为空时这些规则不会执行，而是把自己列进跳过项。

规则库中未被命中的规则同样会出现在结果里：无法执行的检查会连同原因一起列出，空的结果列表不等于材料没有问题，只等于规则库覆盖到的那部分没有发现差异。

严重度含义：错误（7 条）——规则所依据的条文已取得逐字文本，出现差异即为明确不符；提示（1 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（4 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：条文直接规定（8 条）——该规则的依据条文已取得逐字文本，规则直接对照条文规定；由原则推导（2 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」；本机构配置（2 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」。

引用取证状态

引用取证：规则库没有遗留待取证条目。8 条规则直接对照条文；剩下的规则依据原则或本机构配置，不涉及条文原文，因此不存在取证进度问题。

规则库合计引用 5 份文件，引用规则数依次为：《病历书写基本规范》（6 条）、《电子病历应用管理规范（试行）》（3 条）、《护理分级标准》（1 条）、《进一步改善护理服务行动计划（2023—2025年）》（1 条）、《综合医院分级护理指导原则（试行）》（1 条）。同一份文件在不同规则中可能被引用于不同条款。

结果怎么读

本插件共 12 条规则，其中严重度最高的一档是「错误」，共 7 条：NR-001、NR-002、NR-003、NR-004、NR-005、NR-007、NR-011。结果里先看这几条，再回头处理其他规则报出的差异。

还有 2 条规则属于「本机构配置」（NR-008、NR-012）。这几条只有在配置被填写后才会执行；未配置时它们不会静默通过，而是列入跳过。

适用场景与同组插件

面向病案室、质控科与临床科室的病历与编码核对：病案首页、护理记录、ICD 编码结构与星剑号配对。

同一职业分组「医疗病案」下还有 2 个核查插件，分别是ICD 编码规则校验（dsh-icd-rule-check）、病案首页质控（dsh-medrec-qc）。实际使用中往往要跑不止一个：单个插件只负责它自己那份规则库声明过的范围，范围之间不重叠，合起来才接近一次完整复核。

npm 包名 dsh-nurse-record-check，仓库 PerryLink/dsh-nurse-record-check，Apache-2.0 许可。页面上的规则与依据由构建脚本从规则库（版本 2026.1）与包的 locale 资源读出，与仓库内容一致。

  • ICD 编码规则校验 dsh-icd-rule-check —— ICD 合并编码与星剑号配对提示
  • 病案首页质控 dsh-medrec-qc —— 病案首页形式质控与逻辑矛盾提示

安装

安装命令对两个平台是同一个 dsh 子命令，只有随后确认安装结果的那一步按 shell 不同：

bash / sh

dsh plugin --profile default add dsh-nurse-record-check
dsh --profile default --dump-config | grep 'dsh-nurse-record-check'

PowerShell

dsh plugin --profile default add dsh-nurse-record-check
dsh --profile default --dump-config | Select-String 'dsh-nurse-record-check'

若你用的不是 default profile，把名字替换掉即可。安装后需要重启会话，工具才会注册进来。
