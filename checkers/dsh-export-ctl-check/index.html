这个插件核对什么

出口管制核对（dsh-export-ctl-check）是一个面向关务外贸场景的 DeepSeek Harness 核查插件。出口管制物项核对（按管制清单、最终用途与许可证核对台账齐备，仅提示差异，不作出定性结论）

规则库 8 条规则，数量居中：既能覆盖这类材料的主要要素，又不会把无关项也拉进来。依据来源是混合的：「条文直接规定」4 条、「由原则推导」4 条。两类规则的证据强度不同，结果里的严重度已经反映了这个差别。

核对方式

出口管制核对的检查手段集中在以下几类，都不依赖模型判断：必填项存在性（2 条）、条件必填（2 条）、多字段至少填一（1 条）、编号或键不得重复（1 条）、取值须在允许清单内（1 条）、须包含给定要素之一（1 条）。

插件不会替你查证。它只比较材料自身各处之间、以及材料与所引条款之间是否一致；材料里写错的事实，只要内部自洽，就查不出来。

这里没有算术核对——规则库处理的是齐备性、取值合法性与字段关系，不重算任何金额或数量。

它不作什么判断

共同约定只有一条——插件只做「指出不一致」，不做「下结论」。差异清单里每条都带规则编号、依据的文件与条款、以及差异落在材料里的位置。

结果里最高的严重度是「提示」。这不是保守，而是如实的：这些规则所对照的条文没有逐字文本，凭原则推导不足以支撑更强的结论。

不要把空清单当成结论。规则库够不到的地方、以及因为材料缺少必要字段而无法执行的规则，都会连同原因单列；它们既不算通过，也不算失败。

严重度含义：提示（7 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（1 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：由原则推导（4 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」；条文直接规定（4 条）——该规则的依据条文已取得逐字文本，规则直接对照条文规定。

引用取证状态

引用取证：可以逐字对照条文的规则共 4 条，没有一条规则标注「本次未取得」。这意味着规则库对自身依据的声明是完整的：要么引用条文原文，要么明确说明依据并非条文。

把规则按所引文件归并，得到 1 份依据文件，各自被引用的规则数是：《中华人民共和国出口管制法》（8 条）。引用数统计到文件一层；同一文件内的不同条款可能分别支撑不同规则。

结果怎么读

本插件共 8 条规则，其中严重度最高的一档是「提示」，共 7 条：EC-001、EC-002、EC-003、EC-004、EC-005、EC-006、EC-008。结果里先看这几条，再回头处理其他规则报出的差异。

适用场景与同组插件

面向报关、单证与供应链合规岗的关务核对：报关单证一致、商品归类层级、原产地 RVC、出口管制、信用证与滞箱费台账。

同一职业分组「关务外贸」下还有 7 个核查插件，分别是报关单证核对（dsh-customs-doc-check）、滞箱费台账核对（dsh-demurrage-ledger）、预测考核核对（dsh-forecast-penalty）、归类层级核对（dsh-hs-classify）、信用证单据核对（dsh-lc-doc-check）、原产地 RVC 核对（dsh-origin-rvc-check） 等。这几个插件的范围彼此不重叠，也不会互相替代；要覆盖这类材料的全貌，需要挑出对应的几个分别跑。

该插件以 npm 包 dsh-export-ctl-check 发布，仓库在 GitHub 的 PerryLink/dsh-export-ctl-check，采用 Apache-2.0 许可。本页内容由构建脚本从插件自身的规则库与 locale 资源生成，与仓库中的规则库版本 2026.1 对应。

  • 报关单证核对 dsh-customs-doc-check —— 报关单证一致性核对
  • 滞箱费台账核对 dsh-demurrage-ledger —— 滞箱费台账核对
  • 预测考核核对 dsh-forecast-penalty —— 预测准确率考核核对
  • 归类层级核对 dsh-hs-classify —— 商品归类层级一致性核对
  • 信用证单据核对 dsh-lc-doc-check —— 信用证单据条款核对
  • 原产地 RVC 核对 dsh-origin-rvc-check —— 原产地区域价值成分核对
  • 施工天窗核对 dsh-railway-window —— 铁路施工天窗台账核对

安装

下面是安装命令。两个平台用的都是 dsh，第二行是确认安装结果的写法，按你所在的 shell 选一条：

bash / sh

dsh plugin --profile default add dsh-export-ctl-check
dsh --profile default --dump-config | grep 'dsh-export-ctl-check'

PowerShell

dsh plugin --profile default add dsh-export-ctl-check
dsh --profile default --dump-config | Select-String 'dsh-export-ctl-check'

profile 名按实际情况替换。注意安装本身不会热加载——重开会话之后插件才生效。
