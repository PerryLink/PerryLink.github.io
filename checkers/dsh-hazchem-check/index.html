这个插件核对什么

危化品临界量核对（dsh-hazchem-check）是一个面向安全生产场景的 DeepSeek Harness 核查插件。危险化学品临界量与重大危险源辨识核对（按储存量与临界量核对台账自洽，仅提示差异，不作出定性结论）

8 条规则，是本族里最常见的一档规模，大体对应一次认真的人工通读能看住的范围。该规则库的全部规则都属于「由原则推导」：条文未能取得逐字文本，因此每条规则的严重度上限都压在「提示」，不会给出「错误」级结论。

核对方式

从检查方式看，危化品临界量核对用的是几类可以机械判定的手段：多字段至少填一（1 条）、须为可解析数值（1 条）、与阈值比较（1 条）、必填项存在性（1 条）、表头要素存在性（1 条）、条件必填（1 条）。此外还有 2 类出现频次较低的检查方式。

插件不会替你查证。它只比较材料自身各处之间、以及材料与所引条款之间是否一致；材料里写错的事实，只要内部自洽，就查不出来。

它不作什么判断

这一族插件的立场一致：把材料内部能够逐条指认的差异列出来，合规与否、责任归属、以及能否通过审核，都不由插件给出。每条差异都附上它对照的规则、依据的文件与条款和差异位置，便于逐个复核。

严重度上限为「提示」——插件不使用「错误」级，因此结果里不会出现任何定性判断。

结果里的空清单有明确含义，插件对此不作暗示：规则库覆盖不到的部分、以及因缺少必要字段而无法执行的检查，都会单独列出原因。

引用取证状态

引用取证：8 条规则全部为「由原则推导」，没有一条声称依据了逐字条文。其中 2 条如实标注「本次未取得」。这意味着结果里的每一条差异都只能作为线索，不能作为「违反某条条文」的结论。

规则库合计引用 2 份文件，引用规则数依次为：《危险化学品安全管理条例》（4 条）、《危险化学品重大危险源辨识》（4 条）。引用数统计到文件一层；同一文件内的不同条款可能分别支撑不同规则。

结果怎么读

本插件共 8 条规则，其中严重度最高的一档是「提示」，共 8 条：HZ-001、HZ-002、HZ-003、HZ-004、HZ-005、HZ-006、HZ-007、HZ-008。这几条是清单里最需要先看的；其余条目按材料实际内容逐条判断即可。

另有 2 条规则的条文本次未取得逐字文本（HZ-005、HZ-007）。引用这部分结果时请注意措辞：它们是原则推导的产物，不是条文比对的结果。

适用场景与同组插件

面向生产经营单位安全管理岗的台账与预案核对：危化品临界量、应急预案要素、演练脚本、隐患判定、两票与线损。

同一职业分组「安全生产」下还有 6 个核查插件，分别是养殖投入品核对（dsh-aqua-input-check）、演练脚本核对（dsh-drill-script-check）、应急预案要素校验（dsh-emergency-plan）、重大隐患条款映射（dsh-hidden-risk-map）、线损拆分核对（dsh-power-loss-split）、电力工作票核对（dsh-power-ticket-check）。这类材料通常需要同时过几个插件：一个插件只覆盖它自己那份规则库声明过的范围，把几个插件的结果合起来看才是完整的一次复核。

该插件以 npm 包 dsh-hazchem-check 发布，仓库在 GitHub 的 PerryLink/dsh-hazchem-check，采用 Apache-2.0 许可。本页内容由构建脚本从插件自身的规则库与 locale 资源生成，与仓库中的规则库版本 2026.1 对应。

  • 养殖投入品核对 dsh-aqua-input-check —— 水产养殖投入品记录核对
  • 演练脚本核对 dsh-drill-script-check —— 应急演练脚本核对
  • 应急预案要素校验 dsh-emergency-plan —— 应急预案要素齐备性与条款级页码定位
  • 重大隐患条款映射 dsh-hidden-risk-map —— 安全隐患台账→《工贸企业重大事故隐患判定标准》
  • 线损拆分核对 dsh-power-loss-split —— 线损电量拆分与考核表核对
  • 电力工作票核对 dsh-power-ticket-check —— 电力工作票要素齐备性与签发许可顺序核对

安装

插件通过 dsh plugin add 安装，两条命令的主体一致，区别只在装完后用什么方式确认它已经注册：

bash / sh

dsh plugin --profile default add dsh-hazchem-check
dsh --profile default --dump-config | grep 'dsh-hazchem-check'

PowerShell

dsh plugin --profile default add dsh-hazchem-check
dsh --profile default --dump-config | Select-String 'dsh-hazchem-check'

把 --profile default 换成实际使用的 profile 名。装上之后重新启动会话，插件注册的工具才会出现。
