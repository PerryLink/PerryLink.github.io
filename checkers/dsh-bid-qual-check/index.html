这个插件核对什么

资格条件核对（dsh-bid-qual-check）是一个面向招投标场景的 DeepSeek Harness 核查插件。投标人资格条件核对（按资格条件与证明材料核对逐条响应，仅提示差异，不作出定性结论）

8 条规则，是本族里最常见的一档规模，大体对应一次认真的人工通读能看住的范围。依据来源是混合的：「条文直接规定」3 条、「由原则推导」4 条、取自使用机构自身配置 1 条。两类规则的证据强度不同，结果里的严重度已经反映了这个差别。

核对方式

核对方式上，资格条件核对主要使用以下几类机械可判定的检查：。

插件不会替你查证。它只比较材料自身各处之间、以及材料与所引条款之间是否一致；材料里写错的事实，只要内部自洽，就查不出来。

该规则库不涉及数值计算：它看的是要素齐不齐、取值在不在允许范围内、字段之间对不对得上。

它不作什么判断

共同约定只有一条——插件只做「指出不一致」，不做「下结论」。差异清单里每条都带规则编号、依据的文件与条款、以及差异落在材料里的位置。

本插件不产生「错误」级结果，严重度最高为「提示」。它指出的是「此处与依据不一致」，而不是「此处是错的」。

另有 1 条规则的判据来自使用机构自己的配置项，不是国家标准。换机构使用前必须先替换这份配置，否则核对的是别人的口径。

不要把空清单当成结论。规则库够不到的地方、以及因为材料缺少必要字段而无法执行的规则，都会连同原因单列；它们既不算通过，也不算失败。

严重度含义：提示（7 条）——差异成立，但条文未直接规定，或需人工判断后确认；参考（1 条）——只作提示，供人工复核，不构成任何结论。

依据类型含义：条文直接规定（3 条）——该规则的依据条文已取得逐字文本，规则直接对照条文规定；本机构配置（1 条）——阈值或清单来自使用机构自身配置而非国家标准，严重度上限为「参考」；由原则推导（4 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」。

引用取证状态

这套规则库有 2 条规则的条文至今未取得逐字文本（共 8 条）。处理方式是写明而不是绕开：引文字段保留「本次未取得」，依据类型降为「由原则推导」，严重度相应封顶。另外 3 条的依据文本已经取到。

规则库落在 2 份文件上，分布如下：《中华人民共和国招标投标法》（7 条）、《中华人民共和国招标投标法实施条例》（1 条）。同一份文件在不同规则中可能被引用于不同条款。

结果怎么读

本插件共 8 条规则，其中严重度最高的一档是「提示」，共 7 条：BQ-001、BQ-002、BQ-003、BQ-005、BQ-006、BQ-007、BQ-008。结果里先看这几条，再回头处理其他规则报出的差异。

另有 2 条规则的条文本次未取得逐字文本（BQ-004、BQ-006）。这几条的结果适合作为自查提示，若要对外引用，需要先自行补齐条文原文。

还有 1 条规则属于「本机构配置」（BQ-004）。使用前请确认这几条的配置与本机构口径一致，否则核对的是别人的标准。

适用场景与同组插件

面向招标人、招标代理与投标人的文件级核对：投标文件符合性、投标人资格、评标因素评分矩阵、质疑与投诉期限。

同一职业分组「招投标」下还有 6 个核查插件，分别是投标符合性预检（dsh-bid-ca-precheck）、合同立场核对（dsh-contract-stance）、质疑投诉期限核对（dsh-protest-deadline）、规则库自检（dsh-rulefile-check）、招标条款摘录核对（dsh-tender-extract）、评分矩阵核对（dsh-tender-matrix）。这类材料通常需要同时过几个插件：一个插件只覆盖它自己那份规则库声明过的范围，把几个插件的结果合起来看才是完整的一次复核。

npm 包名 dsh-bid-qual-check，仓库 PerryLink/dsh-bid-qual-check，Apache-2.0 许可。页面上的规则与依据由构建脚本从规则库（版本 2026.1）与包的 locale 资源读出，与仓库内容一致。

  • 投标符合性预检 dsh-bid-ca-precheck —— 投标文件符合性预检
  • 合同立场核对 dsh-contract-stance —— 合同条款立场台账核对
  • 质疑投诉期限核对 dsh-protest-deadline —— 质疑与投诉期限核对
  • 规则库自检 dsh-rulefile-check —— 规则库文件自检核对
  • 招标条款摘录核对 dsh-tender-extract —— 招标文件条款摘录核对
  • 评分矩阵核对 dsh-tender-matrix —— 评标因素评分矩阵核对

安装

先在 bash 或 PowerShell 里装上，再确认配置里出现了这个包名：

bash / sh

dsh plugin --profile default add dsh-bid-qual-check
dsh --profile default --dump-config | grep 'dsh-bid-qual-check'

PowerShell

dsh plugin --profile default add dsh-bid-qual-check
dsh --profile default --dump-config | Select-String 'dsh-bid-qual-check'

若你用的不是 default profile，把名字替换掉即可。安装后需要重启会话，工具才会注册进来。
