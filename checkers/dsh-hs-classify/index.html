这个插件核对什么

归类层级核对（dsh-hs-classify）是一个面向关务外贸场景的 DeepSeek Harness 核查插件。商品归类层级一致性核对（按章、品目、子目与商品编号的层级关系核对自洽，仅提示差异，不作出定性结论）

规则库只有 6 条规则，是本族里最精简的一档；它不追求把材料过一遍，只盯住这类材料上最容易出错的地方。该规则库同时包含「条文直接规定」与「由原则推导」两类依据：前者 1 条，后者 5 条。

核对方式

归类层级核对的检查手段集中在以下几类，都不依赖模型判断：格式须匹配规定形式（1 条）、前缀层级关系（1 条）、必填项存在性（1 条）、表头要素存在性（1 条）、编号或键不得重复（1 条）、须包含给定要素之一（1 条）。

插件不会替你查证。它只比较材料自身各处之间、以及材料与所引条款之间是否一致；材料里写错的事实，只要内部自洽，就查不出来。

这里没有算术核对——规则库处理的是齐备性、取值合法性与字段关系，不重算任何金额或数量。

它不作什么判断

共同约定只有一条——插件只做「指出不一致」，不做「下结论」。差异清单里每条都带规则编号、依据的文件与条款、以及差异落在材料里的位置。

本插件不产生「错误」级结果，严重度最高为「提示」。它指出的是「此处与依据不一致」，而不是「此处是错的」。

结果里的空清单有明确含义，插件对此不作暗示：规则库覆盖不到的部分、以及因缺少必要字段而无法执行的检查，都会单独列出原因。

严重度含义：提示（6 条）——差异成立，但条文未直接规定，或需人工判断后确认。

依据类型含义：由原则推导（5 条）——未能取得逐字条文，依原则性条款推导，严重度上限为「提示」；条文直接规定（1 条）——该规则的依据条文已取得逐字文本，规则直接对照条文规定。

这是引用取证记录中的完整编号与效力说明，含发布日期、实施日期、代替关系与强制性说明。规则库核对时对照的是这里列出的版本；若本单位执行的是其他版本，结论不直接适用。

以上文件是插件自己声明的核对依据。规则库中每条规则还单独记录了它对照的具体条款；条款文本能否逐字取得，见下一节。

引用取证状态

引用取证：6 条规则中有 5 条的条文本次未能取得逐字文本，规则库如实写明「本次未取得」并把依据类型标为「由原则推导」，而不是用概括或改写冒充条文。其余 1 条为条文直接规定。

被规则引用的文件共 3 份，按引用次数从多到少是：《中华人民共和国进出口税则》（4 条）、《商品名称及编码协调制度》（1 条）、《中华人民共和国进出口关税条例》（1 条）。同一份文件在不同规则中可能被引用于不同条款。

结果怎么读

本插件共 6 条规则，其中严重度最高的一档是「提示」，共 6 条：HC-001、HC-002、HC-003、HC-004、HC-005、HC-006。结果里先看这几条，再回头处理其他规则报出的差异。

另有 5 条规则的条文本次未取得逐字文本（HC-001、HC-002、HC-004、HC-005、HC-006）。这几条的结果适合作为自查提示，若要对外引用，需要先自行补齐条文原文。

适用场景与同组插件

面向报关、单证与供应链合规岗的关务核对：报关单证一致、商品归类层级、原产地 RVC、出口管制、信用证与滞箱费台账。

同一职业分组「关务外贸」下还有 7 个核查插件，分别是报关单证核对（dsh-customs-doc-check）、滞箱费台账核对（dsh-demurrage-ledger）、出口管制核对（dsh-export-ctl-check）、预测考核核对（dsh-forecast-penalty）、信用证单据核对（dsh-lc-doc-check）、原产地 RVC 核对（dsh-origin-rvc-check） 等。实际使用中往往要跑不止一个：单个插件只负责它自己那份规则库声明过的范围，范围之间不重叠，合起来才接近一次完整复核。

npm 包名 dsh-hs-classify，仓库 PerryLink/dsh-hs-classify，Apache-2.0 许可。页面上的规则与依据由构建脚本从规则库（版本 2026.1）与包的 locale 资源读出，与仓库内容一致。

  • 报关单证核对 dsh-customs-doc-check —— 报关单证一致性核对
  • 滞箱费台账核对 dsh-demurrage-ledger —— 滞箱费台账核对
  • 出口管制核对 dsh-export-ctl-check —— 出口管制物项核对
  • 预测考核核对 dsh-forecast-penalty —— 预测准确率考核核对
  • 信用证单据核对 dsh-lc-doc-check —— 信用证单据条款核对
  • 原产地 RVC 核对 dsh-origin-rvc-check —— 原产地区域价值成分核对
  • 施工天窗核对 dsh-railway-window —— 铁路施工天窗台账核对

安装

下面是安装命令。两个平台用的都是 dsh，第二行是确认安装结果的写法，按你所在的 shell 选一条：

bash / sh

dsh plugin --profile default add dsh-hs-classify
dsh --profile default --dump-config | grep 'dsh-hs-classify'

PowerShell

dsh plugin --profile default add dsh-hs-classify
dsh --profile default --dump-config | Select-String 'dsh-hs-classify'

若你用的不是 default profile，把名字替换掉即可。安装后需要重启会话，工具才会注册进来。
