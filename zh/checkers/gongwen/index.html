公文档案核查插件

3 个插件，规则库合计 20 条。

公文档案分组共 3 个核查插件，规则库合计 20 条，其中 0 条为条文直接规定、5 条的条文本次未取得逐字文本。该分组所有插件最高只到「提示」级，命中表示需要人工确认。面向办公室、文秘与档案室的公文与归档核对：公文格式要素、文种与发文字号、流转时限、归档完整性与保管期限。

面向办公室、文秘与档案室的公文与归档核对：公文格式要素、文种与发文字号、流转时限、归档完整性与保管期限。

同一份材料往往需要同时跑两个以上插件：每个插件只覆盖它自己那份规则库声明过的范围，范围之间不重叠也不互相替代。下面这张表按插件列出核对对象与依据的标准，便于确定该跑哪几个。

逐个插件

档案归档核对

档案归档完整性与保管期限核对（依据《档案法》及配套规定，仅提示差异，不作出定性结论）

规则库 7 条，全部为「由原则推导」，3 条依据本机构配置；严重度分布：提示 4 条、参考 3 条。

依据：《归档文件整理规则》、《机关文件材料归档范围和文书档案保管期限规定》、《中华人民共和国档案法实施条例》、DA/T 22—2015、国务院令第772号、国家档案局令第8号、国家档案局令第10号、2020年修订

安装：dsh plugin --profile default add dsh-archive-check

公文流转核对

公文流转与办理时限核对（按公开的公文处理规范核对环节完整性与时限，仅提示差异，不作出定性结论）

规则库 6 条，全部为「由原则推导」，2 条依据本机构配置；严重度分布：提示 4 条、参考 2 条。

依据：《党政机关公文处理工作条例》、中办发〔2012〕14号

安装：dsh plugin --profile default add dsh-gongwen-flow-check

公文格式核对

公文格式要素核对（按公开的党政机关公文格式标准核对版头与主体要素，仅提示差异，不作出定性结论）

规则库 7 条，全部为「由原则推导」，1 条依据本机构配置，5 条的条文本次未取得逐字文本；严重度分布：提示 6 条、参考 1 条。

依据：《党政机关公文格式》、《党政机关公文处理工作条例》、中办发〔2012〕14号

安装：dsh plugin --profile default add dsh-gongwen-word-check
