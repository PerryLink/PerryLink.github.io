法律诉讼核查插件

3 个插件，规则库合计 22 条。

法律诉讼分组共 3 个核查插件，规则库合计 22 条，其中 6 条为条文直接规定、7 条的条文本次未取得逐字文本。该分组所有插件最高只到「提示」级，命中表示需要人工确认。面向律师与法务的诉讼文书核对：起诉状四要素、证据清单齐备性、法条引用与文书要素的可核验性。

面向律师与法务的诉讼文书核对：起诉状四要素、证据清单齐备性、法条引用与文书要素的可核验性。

同一份材料往往需要同时跑两个以上插件：每个插件只覆盖它自己那份规则库声明过的范围，范围之间不重叠也不互相替代。下面这张表按插件列出核对对象与依据的标准，便于确定该跑哪几个。

证据清单核对

证据清单齐备性核对（按待证事实与证据要素核对清单自洽，仅提示差异，不作出定性结论）

规则库 7 条，其中 2 条为条文直接规定，1 条依据本机构配置；严重度分布：提示 6 条、参考 1 条。

依据：《最高人民法院关于民事诉讼证据的若干规定》、法释〔2019〕19号

安装：dsh plugin --profile default add dsh-evidence-check

法条引用核对

法条引用与文书要素核对（按名称、条号、原文与效力状态核对引用可核验性，仅提示差异，不作出定性结论）

规则库 8 条，全部为「由原则推导」，8 条依据本机构配置，7 条的条文本次未取得逐字文本；严重度分布：参考 8 条。

依据：本机构法律文书审查口径（本机构配置）—— 原挂《中华人民共和国立法法》，已核实其第六十五条为立法技术条款、本机构法律文书审查口径（本机构配置）—— 原挂《党政机关公文格式》GB/T 9704—2012，已核实为版式标准、本机构法律文书审查办法（本机构配置）、无统一标准

安装：dsh plugin --profile default add dsh-lawcite-adapter

诉状要素核对

规则库 7 条，其中 4 条为条文直接规定；严重度分布：提示 7 条。

依据：《中华人民共和国民事诉讼法》、1991年通过，经 2007、2012、2017、2021、2023 年五次修正

安装：dsh plugin --profile default add dsh-pleading-draft
